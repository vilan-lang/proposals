# N147 — `VILAN_STD` pointing at a copy of std with no `macro_std` beside it gives `'Instant' does not implement trait 'PartialOrd': missing 'eq'` (and the same for `Duration` and every derived `Ord`) instead of the split-toolchain refusal the compiler already has

- status: OPEN — filed 2026-10-05 (perf-47's find, Order 47)
- kind: hygiene (diagnostics; S)
- area: Hygiene & rot

Repro: `cp -r vilan/std /tmp/x/std`; a file `import std::time::Instant; fun main() { print(Instant::now() < Instant::now()); }`; `VILAN_STD=/tmp/x/std vilan check t.vl`. `macros::split_toolchain_refusal` words exactly this mistake ("the `macro_std` package was not found beside `std` … a `std` moved away from its toolchain is half a toolchain"), but on this path the derives silently produce nothing and the conformance errors are what the user sees, pointing into std's `compare.vl`. Copying `macro_std` beside the copy fixes it. Sizing S.
