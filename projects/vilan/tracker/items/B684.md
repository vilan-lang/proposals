# B684 — A readonly `&` at a `&mut` parameter checks clean - `bump(&x)` over `fun bump(a: &mut i32)` writes `x` on JS (prints 2) and the native emission is refused by rustc (E0308, reported as a backend defect)

- status: OPEN - filed 2026-10-26 (solver-55's find, Order 55)
- kind: miscompile (JS) / backend defect (native) - a readonly view at a `&mut` parameter
- area: Language

B649's sibling, met probing it: `check_view_arguments` asks a `&mut` parameter only whether the argument IS a view (`assignment_target_is_view`), not whether it is a WRITABLE one, so `&x`, a `&` view binding or a `borrows` call returning `&T` all pass. Rec: refuse with "this parameter takes `&mut`: write `bump(&mut x)`" (the binding must be `mut`, which `check_mutable_references` already says); count the estate first (expected 0: the native backend would have refused every site).
