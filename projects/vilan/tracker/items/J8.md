# J8 — No public cancel handle that reactive state can hold: `OwnedNursery` can't sit in a `Shared`, and `detached_nursery()` is internal

- status: OPEN - filed 2026-11-05 (kolt)
- kind: std gap
- area: Standard library (`std::task`)

A load started from reactive state needs a handle that closures and shared cells can keep, to cancel it later:
- when a newer load supersedes it;
- when the view that started it goes (from an owner's cleanup).

std has two candidates, and neither fits:

- `OwnedNursery` is a `[resource]`, so it can't be held where reactive code keeps its state:
  ```
  Error: `Shared` cannot hold the resource `Option<OwnedNursery>`: a native container's internals are host code the move checker cannot see (v1)
  ```
  A closure that a reactive owner runs at cleanup can't own it either.
- `detached_nursery()` returns a plain `Nursery` that can be stored, and `ambient_nursery.run(n, ..)` plus `n.cancel()` do exactly what's needed. But it's `[internal("a pipe run's nursery ...; an application owns tasks with `nursery` or `OwnedNursery`")]`.

Kolt's reactive-list prototype (`planning/proposal/live/src/live.vl`, `Live::loaded`) uses `detached_nursery()` anyway. Its tests check that a superseded load's `sleep` is cut short, and that disposing the owner a load was made under cancels it.

A related trap the prototype hit: a fetch closure passed in as `async || T` runs WITHOUT the ambient nursery, so its IO isn't cancelled, until its type says `(async || T) context ambient_nursery` (as `std::rpc`'s `dial` does). Nothing warns that a nursery-entered extent doesn't reach a closure parameter. This is by design (contexts are declared), but it was a silent failure: the cancel did nothing and the reply still landed.

**Asked for:**
1. A public, storable cancel handle: either `detached_nursery()` made public, or an `OwnedNursery::handle()` returning a non-resource `Nursery` that can cancel.
2. Possibly a lint: an async closure parameter called inside `ambient_nursery.run` whose type doesn't declare `context ambient_nursery`.

- 2026-11-05 (the integrator, at the sync to main): Synced from kolt-053.
