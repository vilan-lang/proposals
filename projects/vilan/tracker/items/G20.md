# G20 — `vilan check <FILE>` ignores the manifest, so prelude behavior lies in file mode

- status: OPEN — audit run 6's F11; order-material
- kind: bug
- area: Macros & const
- source: audit run 6, repro verified

An explicit file path builds a Unit with no package_dir, so the manifest
is never read in file mode: a package ON the web set is steered to "set
prelude = \"std::web\"" (the edit already made), `prelude = false` is
silently ineffective, and a manifest the validator refuses passes
file-mode check wordlessly. Fix: file-mode check discovers the enclosing
manifest the way the LSP does for a lone buffer (or states, loudly, that
it checked manifest-less); pins for the three lies.
