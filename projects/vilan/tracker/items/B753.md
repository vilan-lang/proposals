# B753 — A function that returns a view of a SCALAR field through `borrows` (`fun title_of(t: &mut Task): &mut str borrows t { t.title }`) checks clean and then fails on both backends: a `TypeError` on JS, rustc E0308 natively; the same function over a struct-typed field works

- status: open - filed 2026-11-25 (the struct-keys paper's probes; reproduced on 0.56.1 and on `next` @30247c7e)
- kind: miscompile (JS: a run-time crash from a program the checker accepts) + backend defect (native)
- area: view returns (`borrows`) of a scalar place; the JS `(base, key)` scalar-view pair; crates/vilan-rust (the returned place is emitted as a value, not `&mut`)

Repro: `proposal/struct-keys-lab/b1.vl`.

```
struct Task { title: str, status: str, meta: Meta }

fun title_of(t: &mut Task): &mut str borrows t {
	t.title
}

fun set(place: &mut str, value: str) {
	place = value;
}

set(title_of(&mut t), "b");
```

- JS: `TypeError: Cannot create property 'undefined' on string 'a'` at `place = value`. The callee returned the field's VALUE, where a scalar view is a `(base, key)` pair, so the write lands on a string.
- Native: `expected &mut Rc<str>, found Rc<str>` on the emitted `t.title` (rustc suggests `&mut t.title`), reported as a backend defect.
- `fun meta_of(t: &mut Task): &mut Meta borrows t { t.meta }` in the same file works on JS (`meta_of(&mut t).owner = "y"` writes through): an aggregate view is the aggregate itself there.
- `set(&mut t.status, "done")`, the view made at the call site, works.

Why it matters beyond the crash: `fun at<F>(s: &mut S, k: Key<S, F>): &mut F borrows s { s[k] }` is the accessor the struct-keys paper relies on (§3.2), and `F` is a scalar as often as not.

Rec: the tail expression of a function whose return is a view is a PLACE, emitted as a view of it: the `(base, key)` pair on JS when the place is scalar, `&mut place` natively. Pin both backends, read and write, for a scalar field, a scalar list element (`&mut list[i]`) and a nested path. Related: B749/B685/B750 (a scalar view consumed as a value), B751 (a view bound to a name natively). Size S-M.
