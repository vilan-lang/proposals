# B213 — `vilan fmt` builds a fresh `TreeWalk` per command-line root, so overlapping roots double-report one file

- status: OPEN — lane watch-26's find (2026-09-03); G22's sibling by symptom, a different mechanism
- kind: bug
- area: CLI & build

`vilan fmt --check src src/pkg` prints `helper.vl` twice (verified
with the G22-fixed binary): G22 gave one walk one identity set, but
`fmt` runs one walk PER ROOT, so the set does not span roots. Fix: one
shared visited set across all of `fmt`'s roots (the `EntryIdentity`
G22 introduced); pin the overlapping-roots case and a disjoint-roots
control; check `check`/`build` for the same per-root shape.
