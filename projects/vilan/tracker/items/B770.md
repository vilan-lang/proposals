# B770 — Native: an enum whose payload holds its own type emits an unboxed Rust enum (rustc E0072); JS is correct

- status: open - filed 2026-11-27 (lane `keys-s3a`'s find; pre-existing on `next` @6744ee9d, no key involved)
- kind: backend defect (native: a checked program does not build)
- area: crates/vilan-rust/src/lib.rs (enum layout)

Repro:

```
enum Tree {
	Leaf,
	Node(Tree, i32),
}

fun main() {
	let t = Tree::Node(Tree::Leaf, 3);
	match t {
		Tree::Node(_, let n) => print(n),
		Tree::Leaf => print(0),
	}
}
```

JS prints `3`. `vilan run --backend rust` stops at rustc, "recursive type `Tree` has infinite size". The payload needs an indirection the emitter does not add.

A variant key into such an enum (B711 S3a) would meet it too.
