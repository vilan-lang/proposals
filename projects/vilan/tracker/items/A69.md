# A69 — a CHAIN LINK inside a `css` block: a dotted item ending in `;` (`.ghost();`, `.flex_row();`, `.custom_method(a, b);`) is a verbatim `Style` method call in written position, while a dotted item with a block stays a condition rule — the element syntax's own rule (dotted = chain link), and the way an app's helpers and std's combinators reach the block

- status: OPEN — the owner's ask (2026-09-07); css-30
- kind: feature
- area: Reactive core & UI

Grammar: `css-item = declaration | condition-rule | chain-link`, `chain-link = "." name ["(" args ")"] ";"`; lowering: the link is emitted at its written position in the chain (the chain sorter's canonical order applies afterwards as to any chain). Pins: a bare link, a link with arguments, a link between declarations, the condition rule untouched; formatter round-trip; kolt's `flex_row`/`ghost`/`select_off` helpers as the read-only exhibit.
