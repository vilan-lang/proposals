# E341 — `vilan run --watch` answers SIGTERM/SIGHUP (and a lone SIGINT) by exiting 130 and leaving the round's node child running - E335's forwarding covers the plain run only

- status: OPEN - filed 2026-10-26 (tooling-55's find, Order 55)
- kind: tooling - `vilan run --watch` and a SIGTERM
- area: Tooling

E335 forwards the three signals to a plain `vilan run`'s program; a watch session registers no child with the forwarding pipeline (its rounds restart children through `ManagedChild::kill` and the brief said to keep that path intact), so a supervisor stopping a watcher still leaves the program holding its port. The repro (`finds/watch_sigterm_orphan.sh <vilan>`) prints `child N STILL ALIVE (orphan)`. Rec: the hook, with no plain-run child registered, kills the watch loop's current child (the loop can publish its pid into the same registry in `Exit` mode: forward, wait up to a bound, then exit 130). `tooling`; XS-S.
