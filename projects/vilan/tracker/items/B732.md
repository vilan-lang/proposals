# B732 — Native: a view method called on `cell.write()` emits Rust that rustc rejects (E0308 on `RefMut`)

- status: open
- kind: bug (native backend)
- area: native backend

Found by lane m199-58, not fixed. `cell.write().some_view()` on a `Shared` cell, where `some_view` takes a view receiver, emits Rust that rustc refuses with E0308 (a `RefMut` where a reference is expected). JS builds it. Needs a minimal repro and a probe under `crates/vilan-cli/tests/native/`. Size S.
