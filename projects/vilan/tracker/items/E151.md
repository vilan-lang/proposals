# E151 — an element-head ATTRIBUTE sorter in the formatter, the import and style-chain sorters' sibling: undotted attributes in a canonical order (`id`, `name`, `type`, `for`, `href`, `src`, then alphabetical), `on:` handlers after them alphabetically, dotted chain links LAST and in written order (a chain's order is semantics — `.child` order, `.styled` then `.when`)

- status: OPEN — the owner's ask (2026-09-07)
- kind: editor
- area: Language server & tooling

Attributes and `on:` handlers commute (each lowers to its own `.attr`/`.on` call on a fresh view before the dotted links); dotted links do not. Rule: reorder within the two commuting groups, never across the group boundary with the links, and keep a link's position relative to the other links. Pins per group, an idempotence pin, and a corpus proof that the emitted JS of every element is byte-identical before and after sorting (build each element in source and sorted order, diff). One reformat commit if the tree moves (kolt is the read-only exhibit: count the heads it reorders).
