# M19 — an unchanged package module is re-analyzed on every LSP analysis and every HMR round

- status: OPEN — filed 2026-09-01 as E106's prime hypothesis
- kind: perf
- area: Performance & footprint
- source: the owner's datapoint (views.vl, theme.vl, client.vl slow; HMR slowed "quite a bit") + the lucide timeline

The BASE_CACHE reuses std worlds keyed by import set; nothing
comparable exists for PACKAGE modules. Since kolt gained the 636 KB
generated `src/lucide/lib.vl` (1791 functions, reachable from
views.vl), every analysis of any client-leg file types all 1791
again — the LSP on each keystroke, HMR on each round — and the
timeline of "slow in many files" matches the day the module landed.
The const-heavy files (theme.vl's declarations, views.vl's const
styles) add the const pass per analysis on top. Direction: cache the
analysis of an unchanged module (content-keyed, like the parse
cache) across analyses within a session — the module's declarations
and typed bodies — invalidated when its content or anything it
imports changes; emission reachability already prunes the OUTPUT,
this prunes the WORK. Measure first with the E106 instruments
(`Vilan: Show Language Server Status`) on kolt read-only; the
numbers decide whether lucide is the whole story.

## SIZED 2026-09-01 (editor-perf)

Lucide was 90% of a client-leg analysis (views.vl 2.22 s vs 0.22 s

(2.2×: views.vl 1.00 s, build 2.46→1.22 s, keystroke-to-diagnostics

`check_generic_bound_satisfaction`) + load/walk/base ≈ 480 ms; lucide
still 4.7× of an analysis. Siblings: M21 (base-cache bypass on
`pkg::` imports), M22 (watch recompiles every leg).

## Tranche 1 BUILT 2026-09-01 (lane perf-25) — item stays OPEN for tranche 2

`check_generic_bound_satisfaction` memoizes `satisfies_trait_bound`
and `unrankable_bound_impls` on the RESOLVED `Type` (ids are per-
occurrence — id keys memoize nothing), nested maps so a hit allocates
nothing; counter `analyzer::generic_bound_checks()`; slope pin red-
first via a planted memo-disable (4→20 call sites: 12→28 evaluations
without, 12→12 with). kolt `checks` 2284→769 ms; maxrss 176→205 MB.
TRANCHE 2 — reuse of an unchanged module's analysis ACROSS analyses —
is a rewrite the paper must sequence: one Analyzer mints entity ids
