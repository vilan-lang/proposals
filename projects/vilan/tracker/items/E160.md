A `StructInitializer { struct_id, written }` context recognised from the token stream (`Name {` … cursor at a field position, comma-separated, `=` not yet typed): candidates are the struct's fields minus the ones already written, each inserting `name = ` (or bare `name` when a same-named binding is in scope, the shorthand), with the field's type and doc as the detail; a nested initializer resolves to the inner struct. Generic structs resolve their fields through the declaration. Pins in `completion.rs` beside `member_completion_lists_fields_and_methods`.
