B565 routed a `Type::Function` receiver through the impl-member route, so the call resolves and runs on JS. Natively the blanket's `T` binds the function item's type, which the backend cannot emit as a value; the annotated binding (`let f: || void = nothing;`, B508's pin) runs on both because the binding is the closure type. Rec: coerce a function-item receiver to its closure type (`function_closure_type`) where a blanket binds it, in the analyzer's recorded substitution, so both emitters instantiate at the closure type; or teach the native emitter a function item value.
