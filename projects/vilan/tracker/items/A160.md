# A160 — A155's warning tells the author something false when the EARLIER writer is reactive: for `<div class(label) .styled(card) />` (label a Signal) it says "only the last write stays: `.styled(card)` replaces what `class(label)` wrote", but in the browser `class(label)`'s binding re-sets the class on every change and the element shows `label` from then on

- status: OPEN — filed 2026-10-05 (papers-47's find, Order 47)
- kind: diagnostics (S)
- area: Reactive core & UI

Probed at b94cb47f under a DOM stub that records class writes: a11's client writes are ["lbl", <card>, "lbl2"] -> final "lbl2", while SSR rendered card's classes; a13 (`.bind_styled(..)` first, `class("x")` second) is the mirror: [<card>, "x", <wide>] -> wide. The winner is whichever writer FIRED last. Fix: when the earlier writer is a binding (a `Source` argument to `attr`/an undotted `class(..)`, or a `bind_*`), the sentence says the two writers take turns and the element shows whichever changed last; same steer (compose into one writer).
