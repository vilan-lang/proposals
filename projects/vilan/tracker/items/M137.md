# M137 — `context::apply` mints one reference entity per threaded context argument — 66,189 on kolt's client leg, 26–48 ms of every analysis (39.5 ms of `entity_map` inserts that double the 179k-entry map, 14.3 ms of `argument_ids` pushes) — where one `Expr::Local(parameter)` entity per (node, context) would do

- status: OPEN — filed 2026-10-10 (incr-50's find, Order 50)
- kind: performance (S–M)
- area: Performance & footprint

Measured with CPU probes per section of the context pass (the patch and recipe are in the finds directory): `contexts+graph` is 115 ms on kolt's client leg, of which `apply` is 26–48 — all of it the `thread_calls` loop. The mutation log (M110 S3) replays the cold rows but still applies them to the tree on every analysis, so the cost stays on a served keystroke. Fix: share one reference entity per (node, context) across the node's threaded calls (~6.9k mints instead of 66k). It changes the tree the emitters read (an entity in several argument lists); gate with the native differential and the corpus goldens, and check first that no emitter memoizes by argument entity. Sizing S–M.
