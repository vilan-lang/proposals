# E108 — a type-position unresolved name in a dependency module attributes to std's lib.vl

- status: OPEN — the prelude lane's pre-existing find (Order 22), reproduced on 0.39.0
- kind: bug
- area: Diagnostics
- source: lane prelude's report, 2026-08-29

An unresolved TYPE-position name in a dependency's module attributes its
diagnostic to std's `lib.vl` at a nonsense span, while the VALUE-position
twin attributes correctly — the value site calls
`attribute_new_diagnostics` and the type site does not. One mechanism,
both positions; pin the type-position case red-first with the file and
span asserted, the value control green.
