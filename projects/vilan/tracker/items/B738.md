# B738 — `std::ui`: a handler that captures its own element makes a reference cycle, so the element lives until the program ends

- status: open
- kind: bug (native UI; lifetime)
- area: crates/vilan-rt-gfx/src/ui, vilan/std/src/ui.vl

Options: handlers hold a weak handle to their own element; removing an element from the tree drops its handlers; or the host breaks cycles when a subtree is detached. Pin with a drop counter in the gfx crate's tests, and add a row to the leak gate if native UI programs enter it.
