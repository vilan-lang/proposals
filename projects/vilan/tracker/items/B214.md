# B214 — `ret` inside `main` emits an illegal top-level `return`: the program compiles, then node throws `SyntaxError: Illegal return statement` (MISCOMPILE)

- status: OPEN — lane bindings-26's find (2026-09-03); Order 26 lane b214-b215 the same day
- kind: bug
- area: Code generation

`fun main() { if flag { ret; } … }` compiles clean; `main` is INLINED
at module scope, so its `ret` lowers to a bare `return` outside any
function and node refuses the whole module at parse time. Fix at the
root in the transformer: an early `ret` in `main` must lower to
control flow that is legal at module scope — emit `main` as a
function invoked once (the simplest sound shape; measure the corpus
byte-diff and the startup cost), or a labeled block break. Pins: an
early `ret` in `main` runs; nested in a loop; `main` returning a
value if the language allows it; the corpus goldens updated only
where `main` contains a `ret`.
