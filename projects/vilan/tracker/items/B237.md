# B237 — `prepped_assignments` wiring skips a target whose local resolves late: an assignment to a guard continuation binding never reaches the wiring's own `cannot assign to this expression` arm

- status: OPEN — lane divergence-27's find (2026-09-04, Order 27)
- kind: bug
- area: Type system & the type solver

B222's guard pass declares the continuation binding after the walk, so an assignment to it is wired before its target exists and the wiring skips it; `check_readonly_mutation` still refuses, which is why nothing is silent — but the wiring's arm is unreachable for that shape and any future check that relies on the wiring would miss it. Re-run the wiring for late-declared targets (the same seam the guard pass uses). Pin: the assignment reports through the wiring's message, not only the mutation check's.
