# F161 — std::db: node binds every number as REAL, native binds integers as INTEGER - an untyped column stores 7.0 vs 7

- status: open
- kind: bug (backend parity)
- area: std::db

Found by lane db-58 and documented in native.md. A column with no declared type stores `7` as `7.0` on JS and as INTEGER natively, because node's sqlite binds every JS number as a REAL. A possible fix: the integer `SqlValue` impls pass a BigInt on JS. Columns with a declared INTEGER affinity are unaffected. Size S.
