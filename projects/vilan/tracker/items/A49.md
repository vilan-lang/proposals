- kind: design

(1) `on_change` landed with a default body wrapping `sub` (swallowing the first call) because a requirement breaks nine shared-test impls, three doc examples and kolt's `StorageSignalCell`; tighten when the migration is scheduled. (2) A closure parameter cannot be typed by a trait (no trait objects), so `bind_each_by` hands the row a writable cell; a `ReadOnly<T>` wrapper would restore the projection. (3) `sync` is refused on a return type and a returned closure captures the creation site's owner, so `selector()` returns a struct with `.of(key)`; a closure spelling needs a context-carrying closure type (`sync`/`context` are parameter-only today).
