N151's measurement: every test process pays a cold std world (nextest's process-per-test), and the per-analysis cost of that world is what opt-level moves. `[profile.dev.package.vilan-core] opt-level = 1` (or the same under `[profile.test]`) is the one lever that reaches all 9,797 tests; it does not change what any test asserts. Measured under load 23-41 on the shared VM: the inference sample's phases fall load+walk 343->128 ms, base 174->45, checks 272->69, post 101->23. A clean O1 build of vilan-core + the inference binary is 2m24s (244 CPU-s). The trade is the owner's: a lane that edits analyzer.rs and runs one targeted pin pays ~60 s more per edit; a full-suite gate saves on the order of an hour of CPU. Rec: try `[profile.test.package.vilan-core] opt-level = 1` for one order and measure both sides (CI's suite legs, a lane's edit loop) before keeping it.
