# E117 — a ghost diagnostic lingers after a comment/uncomment round-trip

- status: OPEN — owner report 2026-09-01
- kind: bug
- area: LSP & tooling
- source: the owner: comment an important line, uncomment it, a ghost error shows briefly ("is this slowness or something else?")

Slowness makes it visible; a correct server never shows it. The
class: diagnostics from a SUPERSEDED analysis (the commented-out
state) publish AFTER the newer analysis (the restored state) has
started or finished — an ordering hole. Standard remedy: stamp each
analysis with the document version it read, and drop any publish
whose version is older than the latest published (or cancel the
older analysis on the next change). Pin with the LSP harness: two
rapid edits, the stale result must never be the last published.

editor-perf lane's exhibit).
