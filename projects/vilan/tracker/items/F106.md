# F106 — a `match` whose SUBJECT is a generic call returning a USER generic enum (`match wrap(3) { Maybe::Just(let v) => .. }`) is refused natively "an unbound generic type parameter (parameter 1 of `wrap`)" — the same subject bound by a `let` first runs, and so does the shape over std's `Option`

- status: OPEN — filed 2026-10-05 (solver-47's find, Order 47)
- kind: bug (native refusal; S–M)
- area: Native targets & rendering

JS prints 3. Base e5e15ca7 and the solver-47 tip alike. `let r = wrap(3); match r { .. }` runs natively, and `fun wrap<T>(item: T): Option<T>` matched inline runs too, so the subject call's instance is reached without its substitution only for a user enum (the call's recorded binding, or the match's subject type, read unsubstituted on the native match path). Pin: a `native_differential` probe of the three shapes. Sizing S–M; native.
