# E328 — a generic enum's payload variant in value position hovers without its payload - `Some` in `Some(1)` reads `Option<i32>::Some` where a pattern reads `Option<i32>::Some(i32)`

- status: OPEN — filed 2026-10-15 (editor-53's find, Order 53)
- kind: editor (hover; XS)
- area: Editor

`variant_value_hover` (vilan-lsp) spells the declared payload only for an enum with no parameters; with E317 the instantiation is known for a constructor call's callee, so the payload can be substituted under the enum's arguments as `pattern_labels` does (`applied_substitution`). Pin: `Some(1)`, `Ok(1)`, `Err("no")` in a return, a binding and an argument.
