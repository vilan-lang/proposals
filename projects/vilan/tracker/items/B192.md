# B192 — a PARTIAL generic-argument list leaves the rest uninferred and dies at emission

- status: OPEN — b186 lane's find (2026-09-01); pinned #[ignore]d
- kind: bug
- area: Type system & the type solver
- source: pin `a_partial_generic_argument_list_still_infers_the_rest` (reason leads with B186 for the gate — retarget)

`tag<Dog>(a, b)` on a two-parameter generic function: the written
argument binds the first, the second is NEVER inferred, and emission
dies with the internal "resolved to a requirement, which has no
body". Supplying none works; supplying all works; supplying some
does not. Pre-existing, no sugar involved. Rule: a partial list binds
positionally and inference fills the rest (Rust's `_` is not needed —
the count is short, not holed); refuse only when the written prefix
is longer than the parameter list.
