# F16 — a closure PARAMETER that is both STORED and CALLED must lower to `Rc<dyn Fn>` on any non-JS backend: the F1 probe's hand translation hit `E0382` (use after move) the moment a callback was pushed into a subscriber list and also invoked — JS hides it because a function value is a reference; the emit-Rust backend needs a rule for which closure values are counted (probe R-1)

- status: OPEN — filed 2026-09-14
- kind: design
- area: Native targets & rendering

Decide in the backend slice: every closure value that reaches a storing position is `Rc<dyn Fn>`; a closure passed and only called stays `impl Fn`/`&dyn Fn`; the fn-coercion paper's coercible set gains the lowering column. Pin: the probe's `board.vl` builds under the rule.
