# G18 — `vilan fmt` and `--watch` follow directory symlinks with no cycle guard

- status: OPEN — audit run 6's F6; order-material (a self-link HANGS fmt,
  zero output)
- kind: bug
- area: Macros & const
- source: audit run 6, repro verified (timeout 124)

`collect_vl_files` (and `collect_manifests`) use `path.is_dir()` — which
follows — and recurse unguarded, while every neighbouring walk fences
symlinks explicitly with the reason written. `src/l1 -> .` hangs
`vilan fmt --check` forever; an ordinary directory link ESCAPES the
package, so fmt will rewrite files in someone else's tree. Fix: the
neighbours' own fence (symlink_metadata, no descent through links) at both
sites; a cycle pin and an escape pin.
