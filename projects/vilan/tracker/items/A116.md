# A116 — HIGH: `[derive(Json)]` on an ENUM crashes on a non-object document — `Shape::from_json("null")` throws `TypeError: Cannot convert undefined or null to object` out of `__json_tag` (`Object.keys(null)`), against `FromJson`'s stated never-crash contract (json.vl:142); a frame off a socket can abort the process

- status: OPEN — filed 2026-09-21 (Order 38 sweep)
- kind: bug
- area: Reactive core & UI

`__json_tag` answers `""` for anything neither a string nor an object, so the derive's `_` arm reports `unknown variant in JSON for enum X`; pins: `null`, a number, an array, an empty object; goldens regenerated and judged by runtime output. A104's `Result` impl already carries its own guard.
