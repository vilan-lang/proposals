# F173 — `std::ui::kit::text_input` has no clipboard: winit 0.30 has no clipboard API and the gfx crate has no clipboard dependency

- status: open
- kind: feature gap (native UI) — RULED 2026-11-12: `arboard`, pinned
- area: crates/vilan-rt-gfx (host), vilan/std/src/ui/kit/inputs.vl

Cut, copy and paste need a clipboard on X11, Wayland, Windows and macOS. Options: `arboard` (the common crate; pulls platform clipboard crates), or our own per platform. QUESTION for the owner: accept `arboard` (pinned, in the gfx crate's notices) or write it. Integrator's recommendation: `arboard`, pinned, behind a `std::gfx` clipboard surface of two functions, so the dependency is replaceable. IME composition (P5) is separate; the edit state leaves room for a preedit run at the caret.

RULED 2026-11-12 (owner: "Yes, all five", accepting the integrator's recommendation): `arboard`, pinned, behind a two-function `std::gfx` clipboard surface so the dependency is replaceable. BUILD: the host and surface first (lane host-58), then the kit's cut, copy and paste keys once the multi-line text area has landed.

BUILT, NOT COMMITTED 2026-11-12 (lane host-58): `arboard =3.7.0`, `default-features = false`, 4 new packages (`arboard`, `clipboard-win` 5.4.3, `error-code` 3.4.0, `objc2-app-kit` 0.3.2; lockfile 364 to 368). LICENCE STOP: `clipboard-win` and `error-code` (the Windows half) are BSL-1.0 ONLY, outside the accepted list (MIT, Apache-2.0, BSD, ISC, Zlib, Unicode); the lane stopped before committing, as briefed. The ruling of 2026-11-12 named `arboard` but not this licence, so it goes back to the owner: accept BSL-1.0 for the gfx crate (the Boost licence is permissive, with no attribution duty for binaries), or write the Windows clipboard ourselves, or ship the clipboard without Windows for now. Surface as built: async `std::gfx::clipboard_text(): Option<str>` (bounded by arboard's 4 s X11 timeout) and `set_clipboard_text(text)`; one clipboard object per process on its own thread, its own X connections (F169 untouched); a real round trip verified against another X client under a private xvfb, 6 of 6; `wayland-data-control` left out (8 more packages; Wayland goes through XWayland). The work is uncommitted in worktree `host-58` and saved as `~/.vilan/gates/host-58/clipboard-f173.patch`. Clean debug build of the gfx crate 48.6 s to 55.5 s (one run each).
