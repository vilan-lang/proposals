# B199 — an `is` capture reached through a CALL ARGUMENT is visible in the then-branch and reads the missing payload

- status: OPEN — b195 lane's find (2026-09-01); B171-era approximation, pinned as-is
- kind: bug
- area: Type system & the type solver
- source: pin `b195_a_capture_off_the_conditions_boolean_spine_keeps_its_b171_answer`

`fun always(b: bool): bool { true }` … `if always(maybe is Some(let n))
{ print(n); }` prints `undefined`: off the condition's boolean spine
(`!`/`&&`/`||`/`is`), the condition's truth proves NOTHING about the
test, so the capture must be invisible in BOTH branches. B195's
polarity frame already drops for off-spine nodes; the fix is to make
"dropped" mean "unbound everywhere" rather than B171's then-branch
default. Miscompile family; the pin runs it. (`while` does not exist,
so there is no loop-condition twin.)
