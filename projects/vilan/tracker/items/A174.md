# A174 — A server cannot take back a mirror it handed out: no way to revoke a connection's subscription to a returned `Store`/source, nor to close a connection from app code, so access that ends (a member removed from an organization) keeps streaming to a client that keeps its lease

- status: OPEN — filed 2026-10-20 (kolt organizations: `organization(org)` returns the org's `Store<OrgState>` after a membership check)
- kind: feature / security (std::rpc server; M)
- area: std

Kolt checks membership when the `[rpc] fun organization(self, org: str): Store<OrgState>` call is made, and every write RPC re-checks it. When an admin removes a member, the removed account's own mirrored account store updates, its client drops the organization, and the lease is released. A well-behaved client stops receiving at once.

The server, though, has no way to *enforce* that. A client that keeps its lease, or a modified one, goes on receiving every update to that organization's channels and messages until it disconnects:

- The forwards a connection holds are internal (`revoke(channel)` and `close_forward` in rpc.vl exist, but app code neither reaches them nor knows the channel id behind the store it returned).
- `Connection` (rpc/server.vl) has no `close()`. `drop_connection` only forgets a wire that has already closed, so the app can't even force a reconnect, which would re-run the checks.

Asks, either of which would do:
1. **Revoke by value:** something like `connection.revoke(store)` / `Service::revoke(connection_id, source)` that ends that connection's subscriptions to a source the service handed out (sending the client the mirror's `Absent`/closed status).
2. **Close a connection:** `Connection::close(reason)` (or a `Service` handle with `close(connection_id)`), so an app can drop a session whose rights changed and let the reconnect re-run `authorize` and the RPC checks. Kolt would also use it when a session is signed out or deleted elsewhere.

(2) is smaller and covers sign-out too; (1) is finer and avoids reconnect churn.
