# F154 — NATIVE: a str-backed enum's `.value()` read at run time does not compile under rustc - `match &*(this)` over an `&Rc<str>` - so A178's `Unit` had to be a plain enum

- status: OPEN - filed 2026-10-31 (std-a178's find)
- kind: native backend (vilan-rust; enum lowering)
- area: Native

`Display`-style enums (`Enum::Variant.value()`, the keyword-property enums use them at const time) lower on the Rust side to a `match &*(this)` that rustc rejects when `this` is `&Rc<str>` - the backing value is matched where the discriminant should be. Const-time uses never reach rustc (folded), which is why the style enums never tripped it. Rec: lower `.value()` on a str-backed enum to the variant's literal through a match on the variant, not on the backing string; pin in the native suite.
