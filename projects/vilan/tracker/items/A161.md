# A161 — fixed-size arrays (`[T; n]`) implement `Items<T>`, so `list.push_many([1, 2, 3])` takes one

- status: OPEN — filed 2026-10-05 (follow-up to A158's ruling; Order 48)
- kind: std addition (S)
- area: Standard library

A158 landed `List::push_many(items)` over the new trait `std::iterator::Items<T>`, implemented by `List<T>`, `HashSet<T>` and every `Iterator<T>`. The owner accepted the trait's name and home (2026-10-05). Fixed-size arrays are not `Items`; this is the follow-up. Both backends, a pin in `inference::std_surface` beside `a158_*`, the native differential.
