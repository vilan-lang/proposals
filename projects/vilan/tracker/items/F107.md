# F107 — natively, a call to an `async fun` whose declared return is a `Task` is not assimilated: the emitted Rust holds a `Task<i32>` where the program has the `i32` (rustc E0369 "cannot add `i32` to `Task<i32>`") — B149's typing is JS-and-analyzer only

- status: OPEN — filed 2026-10-05 (solver-47's find, Order 47)
- kind: bug (native backend defect; S)
- area: Native targets & rendering

B149 types `async fun make(): Task<i32>`'s call as `i32` (the host assimilates the returned handle on JS). The native backend awaits the call once and keeps the inner handle. Rec: a written-`async` callee whose declared return is a handle awaits the handle too (`.await.await` per layer `assimilated_task_payload` strips), or the callee's body awaits its tail before returning. Sizing S; native.
