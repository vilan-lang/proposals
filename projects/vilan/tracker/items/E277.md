# E277 — `dbg`'s layout fills a list of scalars up to the 80-column limit, not one entry per line

- status: OPEN — filed 2026-10-05 (RULED by the owner on debug-47's report)
- kind: tooling (S)
- area: Editor & tooling

debug-47's layout breaks any value past 80 columns one entry per line, so a long numeric list prints as a column. RULED 2026-10-05, as recommended: a list (and set) whose entries are all scalars fills each line to the limit; aggregates keep one entry per line. Both layout runtimes (`__dbg_layout`, `vilan_rt::show`) byte-identical; the 100-entry cap stands.
