# M170 — no empty `View`: a view function with nothing to show (and an `each` row kept only for its effects) must place a DOM element

- status: OPEN — filed 2026-10-24 (kolt: stray space in buttons and menus, from placeholder elements)
- kind: API gap (std::ui; S–M)
- area: Standard library

A child hole already places nothing for `None` (`Option<V: Slot>`), for `ui::when`/`ui::when_some` while false, and an element hides with `View::show`. Two places still need a real element.

**1. A function typed `View` with nothing to show.** `View` wraps an element, so there is no value of it that places nothing:

```vilan
fun notification_bell(): View {
	match model::account() {
		Some(let root) => <button>…</button>,
		None => <span hidden("") />, // has to be an element
	}
}

fun with_org(slug: str, body: |OrgSummary, Store| View): View {
	model::account() is Some(let root) else ret <span hidden("") />;
	…
}
```

kolt has 33 of these, almost all early returns ("no account yet", "no store yet"). Callers place the result as a child, and many sit in flex rows with a `gap`. A bare `<span />` there still takes the gap, which is the stray space kolt chased across 88 placeholders. kolt now uses a hidden span (`styles::nothing()`), so it's harmless, but each one is still an element standing for "nothing".

**2. A keyed scope that owns effects, with no view.** `ui::each` is also how an app gives each key of a reactive list its own owner, so a per-row effect lives and dies with the row. Its body must return a `Slot`, though, so effect-only rows return a dummy element inside a hidden container:

```vilan
<div hidden("")>
	{ui::each(ids, |id| *id, |id| {
		TaskRecord::find(g, id).effect(|found| note(id, found));
		<span />  // only so the row has something to place
	})}
</div>
```

kolt has four of these (link indexes, name probes, the table's record cache).

Recommendation:

1. A `View` (or `Slot`) value that places nothing, e.g. `ui::nothing()` / `View::none()`, backed by an empty `Region` (the anchor `when`/`swap` already use), so view functions can say "nothing" without an element. Letting view functions return `impl Slot` / `Option<View>` would also do, but means changing signatures across an app.
2. A keyed effect scope with no view: `ui::each` accepting a `void` body (rows that are only owners), or a sibling such as `reactive::each_owned(source, key, |item| { … })` that needs no DOM.
