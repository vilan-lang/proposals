# E115 — an element tag's closing `>` on its own line is not highlighted

- status: OPEN — owner report 2026-09-01
- kind: bug
- area: LSP & tooling
- source: the owner (kolt, multi-line element heads)

When an element head's attributes span lines and the closing `>`
lands on a new line, it loses its highlight. Two suspects: the
TextMate grammar's element-head rule is single-line (a `begin`/`end`
pair that cannot span), or the semantic-token pass emits nothing for
a standalone `>` token — the two highlight sources should agree, and
the grammar should not be the only one covering punctuation. Pin the
token: a multi-line head yields the same tokens as a one-line head.
