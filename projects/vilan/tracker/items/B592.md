# B592 — A list literal of array literals under `List<[i32; 2]>` is refused on both backends — "Expected List<[i32; 2]>, but got List<List<i32>>": the element expectation does not reach the inner literals

- status: OPEN — filed 2026-10-09 (native-49's find, Order 49)
- kind: bug (analyzer; S)
- area: Type inference

`let listed: List<[i32; 2]> = [[1, 2], [3, 4]];` is refused; the nested `[[i32; 2]; 2]` annotation is accepted, so a fixed-array element type directs an array literal one level down but a `List`'s element type does not. Expected on both: `[ [ 1, 2 ], [ 3, 4 ] ]`. Repro: finds/list_of_fixed_arrays_literal.vl. Sizing S; analyzer (the literal's expected-type seeding).
