# B568 — a struct literal that writes a std-`[internal]` field is refused outside std — `Store { root = .. }` still builds today, though reading the same field is refused since A149 S4

- status: OPEN — filed 2026-10-05 (RULED by the owner on store-47's report; Order 48)
- kind: language rule (S), breaking
- area: Compiler

A149 S4 (store-47, Order 47) made a member READ of a field std marks `[internal]` a refusal outside std. Construction was outside the ruling and is still allowed. The owner ruled 2026-10-05, as the integrator recommended: refuse construction too, for consistency, with the same reason text (`labels::internal_field_out_of_reach` is the shared rule). Check destructuring patterns that name an internal field at the same time and say what they do. Breaking; count the estate (std, corpus, docs, examples, kolt, website) before the flip.
