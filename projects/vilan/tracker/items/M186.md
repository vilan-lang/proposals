# M186 — A read below any store handle copies the handle's PATH lists on the way down - about 74 `__clone` calls per read of a five-step path, whatever the payload's size (`child_path`, the handle's `path`/`gate` fields)

- status: OPEN - filed 2026-11-02 (lane b693's find)
- kind: perf (std reactive store core; path lists)
- area: Standard library (reactive store)

Every projection allocates and copies the path list of its parent plus one step, and each handle struct literal copies the list again (`root = self.root, path = self.path, gate = self.gate`); a five-step read builds five handles. The payload copy B689/B693 removed was the big term; this is the remaining per-read constant (~10 us on node). Rec: share the path - a persistent cons-list of steps (`Shared<PathNode>` parent pointers: a child's path is one allocation pointing at its parent's, equality/hashing by walking), or build the path lazily only when a slot is asked for (`watch_at`/`identity_at` need it; a plain `get` does not). Measure on kolt's leaf keystroke before choosing. Sizing M.
