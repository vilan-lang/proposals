# F152 — The native HTTP server has no head or body timeout - a client that sends half a head, or declares a body and stalls, holds its connection (and, since M164, a handler awaiting `bytes()`) forever

- status: OPEN - filed 2026-10-26 (http-55's find, Order 55)
- kind: robustness (vilan-rt http; S)
- area: Native targets & rendering

Node bounds both (`server.headersTimeout` 60 s, `requestTimeout` 300 s); `vilan_rt::http` has only the upgraded socket's `setTimeout`. Before M164 a stalled body held the connection unanswered; after M164 the handler runs on the head and a `bytes()` waits on the stalled client (a graceful stop now closes such a connection - `terminate` counts a body being read as waiting on the client). M164's refusal linger (500 ms) is the only timer on the request path. Rec: node's two defaults natively (a head not complete within 60 s closes; a request not answered within 300 s closes, a read in flight cancelled), each a connection deadline polled in `service`.
