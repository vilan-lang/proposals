# M132 — `async_infer::dispatch_candidates` scans every impl of the trait per generic trait call site, with an O(n²) dedup — each generic `.debug()` call std adds costs ~50M instructions (0.8%) on plain:320, superlinear in module count

- status: OPEN — filed 2026-10-09 (debug-49's find, Order 49)
- kind: performance (S)
- area: Performance

Measured building E283 (release, instructions:u): the `HashMap` `Debug` impl's two generic `.debug()` calls cost 6,123M → 6,222M on plain:320 (one call: 6,173M), ~12M on plain:160; callgrind on plain:160 puts the whole delta (+50.4M inclusive) in `dispatch_candidates` under `async_infer::infer`. `trait_method_candidates` walks `program.implementations` per call and `precise.contains` dedups linearly; every `[derive(Debug)]` impl in the program is a candidate for every generic `.debug()`. It is why debug-49 carries ci bumps (x1.004–x1.013) for small std additions. Fix shape: index impls by trait once (or memo per (trait, member)) and dedup with a set. Sizing S.
