# B686 — An `impl Default` (any std trait impl) in a `[platform("@process")]` std module refuses a browser app that reaches a generic `N::default()` - the reach counts every impl in the world as the static call's callee

- status: OPEN - filed 2026-10-26 (http-55's find, Order 55)
- kind: diagnostics/platform reach over-approximation (checker)
- area: Language

Met building M164: an interim `export impl BodyLimits with Default` in http.vl made `vilan check` on kolt's copy refuse its CLIENT entry: `default requires the @process platform its file declares and cannot run on browser`, reach chain `... child (std::web::ui) -> place -> place_swap -> follow -> sub (std::reactive) -> observe_flow -> start (std::reactive) -> start (std::reactive::delta) -> default (std::default) -> default (std::http)`. `MapSum::start` (delta.vl ~3711) calls `N::default()` for the stage's own `N`; the platform walk takes every `Default` impl as reachable, including one whose type no client flow can carry. The lane used an inherent `BodyLimits::new()`; the trap stays for the next std module (or package module) that implements a common trait. A minimal package repro (a @process module with `impl Default`, a browser entry with a `SignalCell`) did not reproduce - the kolt copy with the interim impl is the repro (note: sweeps/order55/http-55/finds/platform_reach_default_impl.md). Rec: the reach of a static trait call `N::default()` is the impls of the types N is instantiated at (monomorphization's answer), not every impl.
