# B207 — `document.rs:287` compares `canonical_path(file)` against `canonical_path(directory)` where `file` may be an UNSAVED buffer: B198's exact shape, unaudited

- status: OPEN — hygiene-25 lane's find (2026-09-01)
- kind: bug
- area: Language server & tooling

`canonical_path` on a path not on disk degrades lexically (G17's
spelled ladder) while the directory side canonicalizes through
links, so an unsaved buffer under a linked project root can fail the
containment test and be treated as foreign — B198's shape in the
LSP. Fix: `util::canonical_path_of_unwritten` (B198's — canonicalize
the deepest ancestor on disk, re-attach the tail as spelled) on BOTH
sides; pin an unsaved buffer under a symlinked root.
