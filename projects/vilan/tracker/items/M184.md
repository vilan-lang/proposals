# M184 — `HashMapCell::at(key)` reads its key through `HashMap::get`, a copy per read - the same keyed step B689 fixed for the store, one layer up

- status: OPEN - filed 2026-10-31 (lane b689's follow-up; proposal/hash-map-lend.md §6)
- kind: perf (std reactive; HashMapCell)
- area: Standard library (reactive)

The cell's per-key handle (`HashMapEntry<K, V>`, a `Source<Option<V>>`) answers `get` by copying the value out of the map; a derive over one field of a large value pays the whole value per wake. Rec: read through `peek` (the handle's lend), `get` copying only at the leaf; pin as B689's: the compiled read carries no `__clone` of the value. Sizing S.
