# B224 — a condition's `&&`/`||` short-circuit is lost in codegen: the right operand's statements hoist before the `if`; an `else if` condition hoists above its whole chain

- status: OPEN — the owner's find while migrating kolt (2026-09-04); confirmed at 289e2a2b by the triage lane
- kind: bug
- area: Type system & the type solver

`if a is Some(let x) && x.on_drag_end is Some(let y) { .. }` emits
`const $a = a; const $b = $a[1][0]; if ($a[0] === 0 && $b[0] === 0)` —
the second `is` subject is evaluated BEFORE the `if`, so a `None`
throws `TypeError: cannot read properties of undefined`. Nesting the
two `is` in separate ifs is correct (the owner's workaround).

The defect is not about `is`: the emitter has no statement slot for a
condition, so ANY operand that lowers to statements is hoisted into
the enclosing block unconditionally. `Expr::Binary` (transformer.rs
~4710) walks both operands into the same block with no `And`/`Or`
case; `Expr::Is` (~5524–5543) pushes the subject temp and
`materialize_captures` there; `walk_branch` (~5484) walks EVERY `else
if` condition into the outer block. Siblings built and run by the
triage lane, all broken: `flag && probe() is Some(let n)` (probe runs
when flag is false), `||`, `!(a is Some(let n)) && ..`, an
if-expression on the right, B215's expression position, the
while-shaped `for` condition, B187's negated continuation, and an
`else if` whose condition runs after an earlier branch was taken.
CORRECT today: `match` guards — B59 gave each leg its own prelude
(~5613–5651); that is the shape to copy.

Fix (M): (1) `And`/`Or` walk the right operand into a scratch; empty →
byte-identical emission; else declare its temps UNINITIALIZED in the
outer block (`let $b;`) and evaluate inline in a comma sequence
`$a[0] === 0 && (($b = $a[1][0]), $b[0] === 0)` — the declaration
hoist is what keeps B187's continuation read (`print(y)` after the
`if`) nameable; a statement that cannot become an expression falls
back to `let $r = lhs; if ($r) { prelude; $r = rhs }`. (2) give
`IfBranch` a prelude slot and lower a prelude-carrying `else if` as
`else { prelude; if (..) }`. A new `Sequence` js node needs an arm in
every post-walk rewrite (`is_divergent`, B214's `ret` rewrite, drops).
The estate has zero right-operand `is` sites, so corpus goldens should
not move. Pins must RUN (every broken program compiles clean):
`assert_compiles_and_runs` (support.rs ~836); guards: b187 (borrows.rs
~7701), b171, b215 ×3, tuples.rs ~576, markdown.rs ~3177 — 55 green
today because each runs only the succeeding path. Related: B187,
B215, B223 (the `for` condition is broken here, the `match` guard is
the one right form), B171/B195/B199 (assume a short-circuit the
emitter does not deliver), B59, B167.
