# J7 — a spawn inside a USER-WRITTEN `context ambient_nursery` closure is NOT registered with the injected nursery: A142 S2's per-run task is cancelled with the run but UNOWNED, so its AbortError is reported on stderr instead of being absorbed

- status: OPEN — filed 2026-09-29 (Order 44, reactive-44's find 7)
- kind: bug (structured concurrency)
- area: Concurrency

A spawn under a closure typed `context ambient_nursery` registers with the nursery the CALLER injected, as a spawn under `nursery(..)`'s body does. Then S2's cancelled tasks report nothing; un-ignore the pin. Sizing S; std/task + the context pass, Order 45.
