# M154 — E145's import-alias spans and the type-reference hover labels are rendered over every file of the world on every analysis — ~11–13 ms of a served kolt keystroke (the largest single row of the extraction tail after M148)

- status: OPEN — filed 2026-10-15 (incr-53a's find, Order 53)
- kind: performance (editor; S–M)
- area: Performance & footprint

`collect_import_alias_spans` walks every expression and every type reference of the program with a `spelling_at` and an alias lookup each, and the `type_references` map renders a `pretty_print_type` label for every written type reference in every file (std's and lucide's included). Both are per-file and a pure function of the settled types and the text, the M148 shape: span-keyed rows per module/item (the label by `(source, span)`), skipped for a restored region, a served item's re-based with its text. The labels are read by hover only; find-references reads the (source, span, definition) triple, which stays. Measured (probe marks, load 10): 'type references labels' 11.4–15.1 ms per served keystroke.
