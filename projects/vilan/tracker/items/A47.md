# A47 — a refused client burns the full retry budget (~24 s of backoff) and reports `Transport("could not reach …")`: the host WebSocket surfaces no HTTP status, so a 401 is indistinguishable from an unreachable server

- status: OPEN — lane rpc-27's find (2026-09-04, Order 27)
- kind: design
- area: Reactive core & UI

`RpcError::Unauthorized` cannot be produced on the socket path today. Options: read the host's error event where a status is exposed (node's `ws` yes; browsers no), or accept the upgrade and send one typed refusal frame before closing (costs a socket per refused attempt — the DoS trade A40 avoided). Decide the shape; pin the client's error on a 401.
