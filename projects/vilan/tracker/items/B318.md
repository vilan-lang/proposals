**RULED (owner, 2026-09-12).** Default private. `export` marks and keeps local. `export *;` per module. `export(PATH)` narrowing. Access never blocked: a reach spelling exists; a dependency's private item reached that way gets NO diagnostic. Warning wording as titled, with the quick fix. `export mod` as the prelude-set spelling. `only`. Type-level impl selection. Importer-scope resolution of `impl PATH`.

**RECOMMENDED (not ruled).** `#` as the reach marker (lexically free: the css lexer refuses `#333` only inside a block; attributes are bracketed). A plain `import a::hidden` of a private item is a WARNING with two fixes ("Export `hidden`", "Import as `#hidden`") so the default flip breaks nothing; `export *;` at the top of every existing multi-file module is the codemod for kolt, the website, the examples and the templates, while std curates real exports. The exposure warning's reach is signature positions: a value's type, parameter and return types, exported struct fields, enum payloads, trait bounds and generic arguments (`List<S>`); never bodies. The fix edits `S`'s declaration wherever it lives (workspace edit); when `S` is a dependency's, no fix, and the message says so. Grammar note: "are unable" → "is unable"/"cannot" for agreement with "a consumer" — the owner's sentence otherwise verbatim. `::*` is legal over any module once exports are explicit (prelude.md §8's 'no globs' was written under everything-public); `export mod` is the idiom. A brace set naming an `impl` selector implies 'these impls only' (so `only` is for statements without a selector); The selector is written in parentheses (RULED): `{ (impl List<i32>) }`, `{ (impl List<i32>)::first }`, `{ (impl List<i32>)::{ first, last } }`; `_` is its placeholder (RULED) and no binders are written in a selector — `_` covers every case with an exhibit (all impls of a type: `List<_>`; a concrete type; nested `List<Option<_>>`; independent positions `Map<_, _>`; and `(impl _)` is 'every impl of the module', the impls-only form), while the one thing binders would add — selecting a block by its BOUND, the `MyTrait` block but not the unbounded one — has no exhibit, and a concrete element type selects both blocks anyway. A method selector refuses `as` (methods are called by name on a receiver). `import a::Length::rem` (B317) binds a static as a free name; `{ (impl Length)::rem }` brings the static into `Length`'s namespace for this file — two different things, both spellable. Impls follow the module's export posture (`export impl …` for an extension impl in a default-private module; `export *;` covers them).
