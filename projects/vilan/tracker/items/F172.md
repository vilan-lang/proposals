# F172 — `std::ui`: no pointer capture, so a drag that leaves its element stops (a text selection stops extending outside the field)

- status: open
- kind: feature gap (native UI; input)
- area: crates/vilan-rt-gfx/src/ui/input.rs, vilan/std/src/ui.vl

While a button is held, pointer moves and the release should go to the element that took the press (implicit capture, as the web and GPUI do), with the option to release it. Needed by drag selection, sliders, scrollbar thumbs, drag and drop. Decide: implicit capture on press for every element that listens, or an explicit `capture_pointer()`. Also from the same lane, same area, smaller: double-click selects a word; a blinking caret (steady today so an idle window draws nothing; a blink needs a timer that stops when the window loses focus).
