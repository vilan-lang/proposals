# F67 — calling a LOCAL closure binding and then reading a member of the result fails rustc: `let make = |n: i32| Row {..}; print(make(1).name)` → E0282; `print(i"{f()}")` with `f = || row.name` → E0277 (str unsized)

- status: OPEN — filed 2026-10-01 (native-45's find, Order 45)
- kind: bug (native refusal by rustc; M)
- area: Native targets & rendering

Cause: the closure literal is cast `as Rc<dyn Fn(..) -> _>` and a cast's `_` resolves too late. Present at the Order 45 base. Rec: write the closure's return type in the cast when it is grounded, non-async and not a view. Sizing S.
