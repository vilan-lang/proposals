# F185 — Native still refuses two parts of `std::fs`: the File handle tier and the watcher (what F156 left)

- status: open
- kind: native backend (std::fs coverage)
- area: crates/vilan-rust (the std::fs intrinsics), crates/vilan-rt

F156 made the members kolt's server reached build natively (`str::index_of`/`last_index_of`, `Instant::to_iso`, the fs options-object calls). Two tiers of `std::fs` are still refused by name on the Rust backend: the `File` handle tier (open, read and write through a handle, seek, close) and `watch`. Neither blocks M1's server; the watcher matters for a native dev loop and the handle tier for streaming files (M178 on the response side). Size each when taken; pin through the native differential as F156's members were.
