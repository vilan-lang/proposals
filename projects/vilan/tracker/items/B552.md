# B552 — a BLOCK-bodied closure handed to a generic callee without a written return — `apply(2, |k| { let d = k * 2; Maybe::Just(d) })` with `apply<T, U>(value: T, f: |T| U): U` — records the call's `U` as `Maybe` with NO type arguments and the block's local `d` as unresolved; JS runs it, natively the instance meets an unbound `T` of `Maybe` (refused by name), and the `let` it lands in carries the argument-less type

- status: OPEN — filed 2026-10-05 (native-47's find, Order 47)
- kind: solver: a recorded type missing its arguments (S–M)
- area: Type system & the type solver

The expression-bodied twin (`\|k\| Maybe::Just(k * 10)`) builds since F85 (native-47). The analyzer side is the cause: an enum type recorded with fewer arguments than its declaration has parameters. Native's `is_grounded` also passes such a type vacuously (`all` over an empty list), so the emitter cannot even see that it is open (an experiment that taught `is_grounded` the arity and bound `U` through the block's tail constructor got the call past, then met the binding's own `Maybe<>` record at the next use).
