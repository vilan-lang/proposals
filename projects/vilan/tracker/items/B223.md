shape B195 refuses in an `if` — because the `while`-shaped `for` and
the `match` guard install no `ConditionPolarity` frame; B215 gave them

uniform fix: a `root(condition_end)` frame for both, which makes
`condition_polarity` non-optional (the real end state) — and REFUSES
programs that compile today, so it is its own item with a census.

refused by B199's per-node narrowing with the generic `cannot find`
rather than B215's message — one rule, two voices; route it through
B215's steer. Pins: the negated `for` condition, a negated guard, the
