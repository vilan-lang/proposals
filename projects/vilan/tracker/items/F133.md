# F133 — Natively a struct with a `[|i32| i32; 2]` field (an array of closures) is refused by name ("does not emit a closure held inside `[Rc<dyn Fn(i32) -> i32>; 2]`, which has no reference equality - `Option` and `List` of one do yet"), so `[derive(Debug)]` over it builds on JS only

- status: OPEN — filed 2026-10-11 (debug-50's find, Order 50)
- kind: native gap (S)
- area: Native targets & rendering

`Option` and `List` of closures are admitted; a fixed array of closures is not. Probe: `struct Callbacks { fns: [|i32| i32; 2] }` with a `[derive(Debug)]` and `Callbacks { fns = [f, f] }.debug()`. Admit the array in the same check as List. Sizing S; vilan-rust.
