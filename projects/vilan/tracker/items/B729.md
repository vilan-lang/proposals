# B729 — Native: F102's refusal is broader than it needs to be - a closure that reaches a `&mut` parameter is refused though it is not an argument of the call holding the view

- status: open
- kind: bug (rust backend)
- area: compiler

Found by lane emit-58b (Order 58, 2026-11-09).
