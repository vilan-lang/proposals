# G16 — the watcher and the stamp disagree on empty nested directories

- status: OPEN — audit run 5's F4; recordable, failure direction safe
- kind: bug
- area: Macros & const
- source: audit run 5

`collect_input_tree` (the watcher) inserts an entry per nested DIRECTORY;
the stamp's `collect_tree` pushes files and symlinks only. An empty
subdirectory created under a declared directory input wakes a round the
stamp then judges Fresh — a spurious round, not a missed one, but it
contradicts "one reading of the manifest, both consumers". Align the two
readings (the stamp learns directory entries, or the watcher stops
inserting them and N30's own-entry rule carries the appearance case).
