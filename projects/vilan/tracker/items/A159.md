# A159 — A155's class-written-twice warning misses two writers: `.bind_attr("class", ..)` and `.toggle_attr("class", ..)` both write an element's class (the second REMOVES it while its flag is false), so `<div .styled(card) .bind_attr("class", s) />` and `<div .styled(card) .toggle_attr("class", flag) />` lose card's classes with no warning

- status: OPEN — filed 2026-10-05 (papers-47's find, Order 47)
- kind: diagnostics (S)
- area: Reactive core & UI

`check_class_written_twice` (vilan-core analyzer.rs:53737) takes `class`, `styled`, `bind_class`, `bind_styled` and `attr("class", ..)` as writers (:53770). `bind_attr` and `toggle_attr` with the literal name "class" write the same attribute on both ui twins (browser ui.vl AttrBinding :2209-2230, toggle_attr :317-327). SSR of the repro prints `<div class="on"></div>` and `<div class=""></div>`; `vilan check` is silent. Fix: add both names to the writer set under the same `"class"` literal test `attr` gets; pins a6/a12 beside A155's five pairs. Sizing S.
