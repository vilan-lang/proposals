# F155 — NATIVE: `groups == groups` on a `HashMap` fails rustc with E0505 - the derived `eq(&self, other)` call moves the operand it also borrows

- status: OPEN - filed 2026-10-31 (lane b689's find)
- kind: native backend (vilan-rust; operator lowering of `==` on a by-value `other`)
- area: Native

`PartialEq::eq(self, other: HashMap<K, V>)` takes `other` by value; the native lowering of `a == a` borrows `a` for `self` and moves `a` for `other` in one expression, which rustc refuses when both are the same place. Rec: lower a by-value operand that is the same place as a borrowed one through a clone (`eq(&a, a.clone())`), or evaluate the operands into temporaries first; pin in the native differential with a map and a struct deriving PartialEq.
