# M674 — no way to find an item's position by a condition (`position`, `find_index`): only `index_of(value)`

- status: OPEN — filed 2026-10-24 (kolt reactions: grouping rows by emoji)
- kind: API gap (std::list / std::iterator; S)
- area: Standard library

`List` has `index_of(value)` (needs `PartialEq`, compares whole items) and `find(predicate)` (the item, not where it is). `Iterator` has `take`, `skip`, `enumerate`, `any` and `all`, but no `position`. So "where is the reaction whose emoji is 👍" is written as one of these:

```vilan
// 1. A throwaway list of the keys, to use index_of on.
match found.map(|each| each.emoji).index_of(emoji) { … }

// 2. By hand.
mut at = 0usize;
for at < found.len() && found[at].emoji != emoji {
	at += 1;
}
```

kolt took the first, in `reactions_of` (store.vl), to update an item in place.

Recommendation: `Iterator::position(predicate): Option<usize>` (Rust's name), and `List::position` delegating to it. `enumerate().filter(…)` gets close, but it's long for something this common.
