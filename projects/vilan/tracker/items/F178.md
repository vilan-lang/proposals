- area: crates/vilan-rt-gfx/src/{ui/access.rs,host/access.rs}, .github/workflows/ci.yml (job gfx), crates/vilan-cli/tests/support/atspi.rs

(1) NOT VERIFIED: Windows (UI Automation) and macOS (NSAccessibility) at run time; they build and pass the Windows cross-lint only. No real screen reader (Orca, NVDA, VoiceOver) was used. (2) The AT-SPI end-to-end test skips where at-spi2-core or `gdbus` is missing, and the CI `gfx` job does not install at-spi2-core, so it may always skip on CI: add the package to the job (a CI change; check the runner image) or accept the skip and say so in the test's doc. (3) Paint-only changes such as hover republish the diff; dropping that needs four one-line hooks in `ui/mod.rs` and `ui/input.rs`. Cost today: full conversion plus diff per published change, 20-25 us on a kit virtual list, 19-33 ms on a plain 10,000-row list (only while a tool listens). (4) WEIGHT, for the owner: a clean debug build of the gfx crate about 29.4 s to 36.8 s; `ui-todo` native 36 s to 44 s (one run each); the audit prints three `unmaintained` warnings (zbus_names, zvariant, zvariant_derive: RUSTSEC-2026-0370..0372). If that is too much, put the adapter behind a cargo feature that `vilan build` enables by default and a manifest key can turn off. (5) DECIDED IN LANE, owner may overrule: the names `checked`, `disabled_state`, `items_shown`, `Element::accessibility()`; a text is published as a label whose value is its text; a button's, checkbox's, link's and heading's children are not published on their own; a click on a covered element does nothing; set value types through Ctrl+A on every platform; windows are made hidden, given their adapter, shown, then given their GPU surface. (6) INCIDENT 2026-11-12: a manual probe ran AT-SPI's launcher without a private runtime directory and wrote the accessibility switch into the owner's dconf; removed, reported to the owner; the committed test uses a private `XDG_RUNTIME_DIR` and `GSETTINGS_BACKEND=memory`, and `AGENTS.md` warns.

RULED 2026-11-12 (owner: "Yes, all five"), on (4): accessibility stays ALWAYS ON; no cargo feature. The 57 packages and the build time stand.

CONFIRMED 2026-11-12 on (2): CI run 43347918404 (next 2f7aa355), job gfx: `the_todo_list_is_driven_through_the_accessibility_bus` passed in 0.013 s, which is the skip path. The AT-SPI proof runs only on this box until the job installs at-spi2-core.
