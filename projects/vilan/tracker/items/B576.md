# B576 — B573's other readers: every diagnostic the PRE-ENTRY `resolve_world` produces for a MODULE renders the analyzer's DEFAULT platform — a browser package's module calling `View::render` is told "`View` here is std's browser twin — this file is analyzed under node" (the same call in the entry says "under browser"); `platform_reason` and `prelude_repair` are read there before `analyze_over_world` assigns them too

- status: OPEN — filed 2026-10-08 (papers-a-48's find, Order 48)
- kind: diagnostics (XS fix, S with the cache rule) — analyzer, same root as B573
- area: Compiler

Repro (`finds/p1_note`, `target = "browser"`): `m.vl`: `import std::web::ui::{ View, view }; export fun show(): str { let v: View = view("div"); v.render() }`; the entry calls `show()`. `vilan check .` -> "View has no method 'render'" with the note "... this file is analyzed under node". `finds/p1_note_entry` (the same function in the entry) -> "... analyzed under browser". Cause: `analyze_inner` runs the module walk and the pre-entry `resolve_world` on an `Analyzer::new()` whose `platform` is `Platform::default()` (node); `analyze_over_world` assigns `platform`, `platform_reason` and `prelude_repair` afterwards (analyzer.rs ~75598-75604). Readers before the assignment: `select_platform_twins` (B573, the miscompile), `overlaid_std_type_note` (~31148, this find), the fenced-out steer in `scope_miss_steer` (~54176, names the wrong platform), and `web_prelude_steer` (~54215, reads `prelude_repair`). B573's one-line fix (`analyzer.platform = platform` right after `Analyzer::new()`) also fixes this note, and is cache-safe because `platform` is in `BaseCacheKey`. `platform_reason` and `prelude_repair` are deliberately NOT in the key ("it changes what one diagnostic says"), so assigning them early would bake one front end's wording into a stored world another front end is served: the rule is that a stored world's diagnostics may not render an unkeyed workspace fact — render those lazily at publish, or key them. Fix with B573 (incr-48's driver) and pin the module note on a browser package. Sizing XS (platform) / S (the two unkeyed facts).
