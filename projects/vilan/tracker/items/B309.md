# B309 — a `context` clause lives on a PARAMETER and nowhere else: `body: (sync || View) context owner_scope` as a STRUCT FIELD is refused three ways ("a `context` clause is only supported on a parameter's closure type"; "a `sync` closure contract is only supported on parameters"; "an injected closure can only be called, forwarded to a parameter with the same `context` clause, or passed to `run`") — the clause is recorded side-band by parameter id (`analyzer.rs:3589` `parameter_contexts`), `Type::Closure` (`type_.rs:41`) carries none, and `context.rs` keys `value_contexts` on locals, so a clause flows through no field, generic argument or return type. This is the wall A85 (positional slots as `Slot` VALUES) hit: a value form must hold its body, and a plain-closure field CAPTURES AT CREATION, so every body/row/page leaks into the enclosing boundary (measured by slots-33). Two shapes: (1) the clause IN the type — `Type::Closure` gains the context list (a core-enum change: every `_ =>` over `Type` is audited, the AGENTS.md rule), so a field, a generic argument and a return can carry `context owner_scope` and the coverage check follows the value wherever it flows; or (2) a parallel `field_contexts` map keyed by (struct, field) with construction rules (a field so typed accepts only an injected closure or a literal born under the clause's extent) and field-read rules (reading it yields an injected value with the same restrictions a parameter has: call, forward, `run`). (1) is the honest one — the clause IS part of the closure's type, and (2) recreates the parameter side-band a second time. Either way the capture rule is unchanged (capture at creation); what changes is that a closure LITERAL written where a context-typed field is initialised is born under the clause's demand, exactly as an argument to a context-typed parameter is today. Pins: the four `bounds.rs` exhibits flip; a value-form `Conditional { body }` built inside `owner_scope.run` and placed later runs its body under the owner ambient at PLACE time (the `run` inside `place`), and a `Conditional` built outside any owner is refused at construction. Spec: contexts.md's parameter-only sentence becomes the type rule.
