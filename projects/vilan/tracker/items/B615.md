# B615 — A `&` of a call's SCALAR result handed to a `&i32` parameter checks clean and crashes on JS — `fun read(value: &i32): i32 { *value + 1 }`, `read(&seven())` throws `TypeError: Cannot read properties of undefined` (`value[0][value[1]]`: the view pair read off a plain number); natively it prints 8

- status: OPEN — filed 2026-10-12 (native-51's find, Order 51)
- kind: miscompile (JS; S)
- area: JS backend

The JS transformer lowers a scalar view as a `(base, key)` pair and a `&` of a temporary scalar hands the number itself. Either the `&` of a temporary scalar builds a one-slot holder (`[[7], 0]`), or the checker refuses a view of a temporary scalar. Met writing F129's probe (`lent(&d.read().items, &grow(d))` with `grow` returning `i32`). Sizing S; the transformer (fix-51's) or the checker.
