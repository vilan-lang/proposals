# N207 — Tracker ids are allocated per local branch: kolt-side sessions file vilan items on unpushed `kolt-*` branches of the proposals repository, where they collide with main's ids and stay invisible to the integrator

- status: open
- kind: process (tracker; an owner decision)
- area: proposals (branches kolt-mirror, kolt-packages, kolt-image-gaps, kolt-overlay-owner, kolt-list-any, kolt-053), scripts/integration/file_items.py

Recommendation, the owner's to rule: a kolt-side session files on MAIN (pull, `file_items.py`, push; proposals main is pushed as it goes since 2026-11-10), and never on a branch. If a branch must be used, `file_items.py` should take the next id from `origin/main` and refuse one that any local `kolt-*` branch or main already holds. Until ruled, the integrator checks `git diff --name-status main...<branch> -- projects/vilan/tracker` over those branches before filing and at every seal. The stale branches and their worktrees under `proposals/.claude/worktrees/` can be reaped once the owner confirms nothing else lives there (kolt-053's items and its `proposal/struct-keys.md` are on main already).
