# M14 — a std function that stops being an extern changes its price, and nothing prices it

- status: OPEN — audit run 5's F7; order-material, and a proposed standing angle
- kind: perf
- area: Performance & footprint
- source: audit run 5

F14's `to_lowercase_ascii` went from one native call to a per-code-unit
vilan loop (per unit: `charCodeAt`, a bounds-checked `__substring` minting a
1-char string, a `+` concat, and in the A–Z branch a four-call numeric
chain). Ten call sites are short tokens; `document.vl`'s `skip_raw_text`
folds the ENTIRE markup document once per `<script>`/`<style>` element —
the one cliff. The CHANGELOG priced nothing (the lane recorded "no
asymptotic change" against `index_of`'s own O(n·m), which is true and
incomplete). Asks: (1) price the cliff site — a cheaper shape for
`skip_raw_text` (fold once per document, or a windowed compare) or a
measured "fine, recorded"; (2) audit run 6 carries "std's emitted cost"
as a standing angle beside the shipped sentence, per the run-5 charter.
