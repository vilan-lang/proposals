# F121 — natively, a struct with a fixed-array field does not build: the emitted `impl vilan_rt::Js for Pixel` casts `&self.rgba as &dyn vilan_rt::Js` and vilan-rt has no `Js` impl for `[T; N]` (it has `Json`'s) — rustc E0277 "the trait bound `[u8; 4]: Js` is not satisfied"; JS prints the field

- status: OPEN — filed 2026-10-09 (papers-49's find, Order 49)
- kind: bug (native backend; emitted Rust refused) (XS)
- area: Native targets & rendering

Repro (`finds/native_struct_array_field.vl`, vilan 0.46.0, `vilan run --backend rust`): `struct Pixel { rgba: [u8; 4] }`, `let p = Pixel { rgba = [255u8, 0u8, 0u8, 255u8] }; print(p.rgba[0]);` -> JS `255`; natively rustc refuses the struct's emitted `Js` impl (`vilan_rt::js_items(&[&self.rgba as &dyn vilan_rt::Js])`), E0277, before the program prints anything — the impl is emitted for every struct, so any struct with an array field fails, printed or not. `dbg` of a local array works (p31) and `Json for [T; N]` exists (`vilan-rt/src/lib.rs` ~1862). Fix: `impl<T: Js, const N: usize> Js for [T; N]` in vilan-rt (rendered as a list, as `dbg` and node print one), and the same audit for vilan-rt's other per-type traits; pin on the native differential (a struct with an array field, printed whole and by element). Sizing XS; native.
