# B169 — an unbounded generic right operand still escapes `+`'s typing

- status: OPEN — b148's recorded residual (Order 22), pinned `#[ignore]`d
- kind: bug
- area: Type system & the type solver
- source: lane b148's report, 2026-08-29

B148's fix types `+`'s grounded operands; an UNBOUNDED generic right
operand still escapes (B24's own leniency): `fun show<T>(value: T): str
{ "v=" + value }` compiles and prints `v=1,2` for a tuple-backed value.
The fix wants the check at instantiation (each monomorphization's grounded
operand re-judged) or a bound requirement on the operand position; either
way the `#[ignore]`d pin in platform.rs is the acceptance test and names
this item.
