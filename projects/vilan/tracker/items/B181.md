`both(true, Point { x = 1, y = 2 })` prints `[ 1, 2 ]` — the value
itself, typed `bool`. Same membership principle as B179 (bool's set
has no characterizing trait), but the logical operators model no
operator trait, so the fix is a refusal in the existing `And | Or`
arm — one line for the right operand, per the lane. The generic LEFT
half is B174's deferral shape and waits with it.
