# F98 — native: a `const` value that is not plain data (a `Style`, a struct) is refused by name — css-block.vl, preflight.vl, style-when.vl, style.vl, theme.vl, five of the 27

- status: OPEN — filed 2026-10-05 (native-47's find, Order 47)
- kind: native refusal by name (M)
- area: Native targets & rendering

The const channel hands the emitter a value, and the native emitter renders only strings, booleans, numbers and lists of those. A `Style` is a struct of lists and strings; rendering a const struct literal from the evaluated value would admit all five (they print class lists, platform-free).
