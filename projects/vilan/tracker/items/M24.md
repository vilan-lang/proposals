# M24 — BASE_CACHE has no eviction: one retained world per (std seeds × sibling set × package root), overwrite-only

- status: OPEN — perf-25 lane's find (2026-09-01); M11's standing finding, now multiplied by M21
- kind: performance
- area: Language server & tooling

M21 keys the base cache on the entry's package root plus its sorted
sibling set, so an N-file package can retain N worlds; eviction is
still per-key overwrite only. `base_cache_retained()` counts them
and the leak tally records the bytes, so the growth is VISIBLE, not
bounded. Fix: an LRU with a byte budget (retained-world bytes are
already measured), evicting least-recently-hit; pin the bound with a
synthetic package of many entries. Sequence after M23 (which changes
what is stored).
