# F136 — Natively an aggregate holding a MAP of closures — a handler table, `struct Table { handlers: HashMap<str, |i32| i32> }` — is refused by name ("which has no reference equality — `Option`, `List` and a fixed array of one do"); JS runs it

- status: OPEN — filed 2026-10-12 (native-51's find, Order 51)
- kind: native gap (S)
- area: Native targets & rendering

F133 admitted a fixed array of closures; a map is the next shape (`vilan_rt::Map<Hash, (Str, Rc<dyn Fn>)>`). `vilan_rt::ReferenceEq` needs an impl for the map and for its `(key, value)` entry tuple, whose key compares by value — the impls are written out per shape, not blanketed over `T: PartialEq` (they would overlap). The equality is unobservable from vilan (closures are not `PartialEq`), so a table that refuses no shape it could build is the goal. Sizing S; vilan-rt + vilan-rust.
