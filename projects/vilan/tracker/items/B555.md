# B555 — `import std::js::null;` is refused with the generic import-path parse error: the module's name is a keyword, so the one std module that cannot be imported by its own name gets no steer

- status: OPEN — filed 2026-10-05 (perf-47's find, Order 47)
- kind: diagnostics (S)
- area: Language & type system

Met while measuring M120 (every std module imported unused, one by one). `import std::js::null::{ .. };` is the working spelling. The refusal ("an `import`/`use` path is `::`-separated NAMES …") does not say that `null` is a keyword here or name the brace form. Rec: steer to `std::js::null::{ … }` at that token. Sizing XS.
