# B759 — Native: `print(w)` of a view BINDING over a scalar (`let w = same_c(&mut n); print(w)`) is refused by rustc (E0277, `&mut i32: Js`); JS prints the value

- status: open - filed 2026-11-26 (lane `b758-generic-view-return`'s find; pre-existing on `next` @a510e123, concrete callee, not B758)
- kind: backend defect (native: a checked program is refused by rustc)
- area: crates/vilan-rust (a view binding handed to `print` without `*`)

Repro:

```
fun same_c(x: &mut i32): &mut i32 borrows x { x }
fun main() {
	mut n = 1;
	let w = same_c(&mut n);
	w = 6;
	print(w);
}
```

JS prints `6`. Native: `error[E0277]: the trait bound `&mut i32: Js` is not satisfied` at `vilan_rt::print`, reported as a backend defect. The emitter hands `print` a reference to the binding, which is itself a `&mut i32`; `print(*w)` builds.

Rec: where a view binding is read as a value (an argument that is not a view parameter), emit the reborrow (`&*w`), as the emitter does for a view parameter. Size S.
