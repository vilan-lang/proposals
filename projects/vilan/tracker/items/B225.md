# B225 — the struct-literal door reopens the enclosing impl's OWN rigid parameter: `impl Pair<type T> { fun make(x: T) { Pair { b = "s", a = x } } }` silently returns `Pair<str>` (B219's first live consequence)

- status: OPEN — the owner's find while migrating kolt (2026-09-04); reproduced at 289e2a2b by the triage lane; narrower than reported — the trigger is the enclosing impl of the SAME struct
- kind: bug
- area: Type system & the type solver

The owner: `Searchable { list, table = list.map(|l| l.map(|x| key(x).
to_lowercase())) }` with both fields `SignalCell<List<T>>` accepted
`SignalCell<List<str>>` against T. Reproduced, no errors anywhere:
`struct Pair<T> { a: T, b: T } impl Pair<type T> { fun make(x: T) { Pair
{ b = "hello", a = x } } } fun main() { let p: Pair<i32> = Pair::make(1)
}`. Discriminators: the same literal inside `impl Holder<type T>` errors
correctly on the field; a plain generic `fun` errors correctly; fields
swapped accept the body but error at the call site. So rigid T leaks
only when the literal's struct IS the impl's subject — kolt's search.vl
is exactly that shape (`impl Searchable<type T>`, `fun new` with no
return annotation).

Cause: the struct-literal door B211 installed (analyzer.rs ~33926):
`let previously_inferable = std::mem::replace(&mut self.inferable_
generics, generic_param_ids.clone())` — the comment intends "a literal
instantiates the struct's parameters, so they are open here even inside
an `impl Boxy<type T>` … `map<U>` binds T := U". But an impl binder
INHERITS the subject's constraint ids (B77), so this reopens the impl's
own rigid T unconditionally. One field binds T := str; the field
carrying the genuine rigid T passes anyway because `compare_type_rigid`
(~28102) is called with an empty rigid list from everywhere but trait
conformance and falls through its `(Type::Generic(_), _)` hole — that
is B219, and this is its first known consequence.

Fix (M, medium risk): open FRESH ids for the struct's parameters at
the door and reconcile the impl's rigid T against them one-way, rather
than aliasing the impl's ids; or restrict `inferable_generics` to
parameters not held by `rigid_binder_scope` — which preserves `map<U>`
(U is not the impl's binder) and refuses this. Landing B219 is the
independent backstop. Census required: B211 shipped the door
deliberately. Pins: the lane's `i1/*.vl` set in scratch
`triage27/checker/` (h_pair_impl_swap must refuse; g_other_impl,
d_minimal stay as they are). Related: B211, B219 (promote: reproduced
silent unsoundness), B77.
