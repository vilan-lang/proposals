# E330 — A two-operand binary whose right operand is a call (`a == b + 1 && starts_with(write.path, held.path)`) breaks the CALL's arguments one per line while the `&&` stays inline: `&& starts_with(` ... `)`

- status: OPEN - filed 2026-10-15 (fmt-53's find, Order 53)
- kind: fmt layout question
- area: Formatter

E321's refusals cover chains of three or more operands; a two-operand chain has no operator split (E147's threshold), so the call's arguments are the only break left and the result reads `let a_key = x == y + 1 && starts_with(\n\twrite.path,\n\theld.path,\n);` (std reactive/store_core.vl, two sites). Accepted with the layout; alternatives: refuse the call-in-a-2-operand-chain too (the line stays long, as before E321), or let a 2-operand `&&`/`||` chain break at its operator when its right operand is a call. Owner's taste.
