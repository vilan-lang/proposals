# M676 — `std::web::dom::Event` has `prevent_default` but no `stop_propagation`

- status: OPEN — filed 2026-10-24 (kolt document comments: a click inside a card that also has a click of its own)
- kind: API gap (std::web::dom; S)
- area: Standard library

A clickable card holding its own buttons (a comment card that selects its region on click, with Resolve inside it) needs the button's click to stop at the button. `Event` has `prevent_default` and `default_prevented`, but no `stopPropagation`. kolt declares its own:

```vilan
impl Event {
	[extern(method, "stopPropagation")]
	external fun stop_propagation(self): void;
}
```

Recommendation: add `stop_propagation` (and `stop_immediate_propagation`) to `Event` beside `prevent_default`, and `cancel_bubble`'s reader if wanted.
