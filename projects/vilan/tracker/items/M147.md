M141's S half (shipped): `candidates_of` memoised per (import scope, name) (-13 M), the refined edges built lazily (a program with no runtime path to a channel verb pays none - kolt's has one through std's style functions), the explicit pass's local index holds only the locals inside a const expression (-10 M); 210 M -> 187 M, -0.28 % of the check. (3) `ConstWorld::reach_from` (17.5 M): sites share a large sub-closure (the style chain), so a memo per EmissionId (or an SCC close) beats re-walking `requires` per site.
