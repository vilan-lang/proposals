# N30 — an empty directory appearing where a listed one was missing starts no watch round

- status: OPEN — audit run 4 finding 10; narrow
- kind: bug
- area: Dev loop
- source: audit run 4, 2026-08-29

The const walk records `(directory, None)` on a failed listing — the miss
doctrine — but `insert_watched_input`/`collect_input_tree` expand a directory
to its FILES and insert nothing for the directory itself. A recorded-missing
directory that appears EMPTY adds no snapshot entry and fires no round, while
the compile that failed on it would now succeed. Narrow: the first file
created inside it does fire. Fix: a recorded directory contributes its own
snapshot entry (existence + membership), not only its files'.
