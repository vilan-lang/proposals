# K26 — the vilan SITE, the PLAYGROUND and the DOCS use ELEMENT SYNTAX (`<div class(..)> … </div>`) wherever it applies, instead of `view("div")` builder chains

- status: OPEN — filed 2026-10-01 (the owner's item)
- kind: docs + examples (M)
- area: Web presence (site, playground, docs delivery)

Scope: vilan-website's own source, every playground example, the book/std docs' UI snippets and the examples directory's UI programs. Where it applies: a statically-shaped element tree. Where it does not (say so in a short style note in the docs): a dynamically chosen tag, a builder passed around as a value, a chain that is mostly reactive bindings — decide the rule from what reads better, write it down once, apply it uniformly. No behaviour change: emitted output stays identical where the desugar is the same (the site's build and the doc snippets' tests are the proof). `vilan fmt` formats the result. Sizing M; a docs/web lane.
