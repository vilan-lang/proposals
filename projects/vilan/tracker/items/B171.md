# B171 — the spec says `is` bindings scope to nothing; the compiler scopes them properly

- status: OPEN — lane b166's finding (Order 22); a RULING, not just a rewrite
- kind: design
- area: Type system & the type solver
- source: lane b166's report, 2026-08-29

`spec/types.md:518` reads "bindings inside an `is` pattern are scoped to
nothing (use `match` to bind)" — false three ways, probe-verified: the
then-branch sees the binding, the binding dies after the `if` (a later
read refuses), and `if x is Some(let n) && n > 0` sees it in the
condition's right operand. The rewrite is a RULING about the exact scope
(then-branch; the rest of the condition after the test; negation and
`||` arms presumably not), which the lane rightly declined to restate
quietly. Rule it, write it, and pin the boundary cases the sentence
draws (the `&&`-operand yes, the `||`-arm no, the else-branch no).
