# F91 — native: an `is` capture to the left of `&&` in an `if` CONDITION, read in the `if` BODY — `if held is Some(let name) && name.len() > 0 { print(name) }` — is rustc E0425 ("cannot find value `name`"): the conjunction emits `match held { Some(name) => cond, _ => false }`, so the capture is scoped to the arm, not the body

JS prints the capture. `conjunction` (vilan-rust) answers a capturing `&&` chain as a nested `match` that yields a bool, which is right for the condition and leaves the body outside the binding's scope; only a bare `if x is P(let v)` takes `if let`. The emitted crate is edition 2024, so a let-chain (`if let Some(name) = held.clone() && name.len() > 0 { .. }`) states it directly. Repro: finds/is_capture_conjunction_body.vl. Sizing S; native.
