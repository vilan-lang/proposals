# A40 — the rpc WebSocket upgrade authorizes nothing and never echoes a subprotocol; a pre-upgrade `authorize` hook + a token subprotocol (transport-rpc Q4's transport half)

- status: OPEN — the owner's ask while migrating kolt (2026-09-04); triage lane confirmed at 289e2a2b
- kind: design
- area: Reactive core & UI

The owner: anyone can connect to the socket (DoS); require a token,
but inject the auth mechanism (JWT, user/pass) from dev-land rather
than bake it in; the browser WebSocket API carries no header but the
subprotocol list, so pass the token beside the real protocol.

Today, none at any layer: `accept_socket` (process/rpc_server.vl
~319–336) checks only that `sec-websocket-key` is PRESENT, writes 101
+ `Sec-WebSocket-Accept`, never reads `sec-websocket-protocol`, never
echoes one, never checks origin; the SSE/POST legs (~232) are equally
open. `request.headers()` is in scope (process/http.vl ~65) and
`NodeSocket` is raw, so the hook has its seam: `fold_service_upgrades`
(~293). Client: `new_web_socket(url)` (rpc.vl ~318) — one argument, no
protocols; generated `connect(url, codec)` (~1933) has no token seam.
`RpcError::Unauthorized` (~852) exists and std never constructs it.
transport-rpc Q4 (✅ settled ~1129): manual auth, identity in the
per-connection session, no `[rpc(auth)]` — but AFTER the socket is up;
zero hits for subprotocol/DoS in the four papers. An extension of Q4,
not a re-litigation.

Shape: `Handshake { path, headers, protocols, remote_addr }`, `Reject
{ Unauthorized, Forbidden, TooMany }`; `Service::factory(..)
.authorize(|hs| -> Result<Session, Reject> { let token =
hs.protocols.find(|p| p.starts_with("token."))?; verify_jwt(..) })`
run BEFORE the upgrade: `Err` writes 401/403 and destroys the socket
(no socket, no session, no ReactiveServer); `Ok(session)` feeds A38's
factory. Client: `connect(url, codec, protocols = ["vilan-rpc",
"token." + jwt])` — one extern change. The server MUST echo
`Sec-WebSocket-Protocol: vilan-rpc` or the browser closes the
connection; that echo is missing today and is required even for the
bare `["vilan-rpc"]` offer. In scope, ~20 lines on the same seam:
`max_connections`, per-IP handshake rate, a handshake timeout — the
part that works with auth absent; needs a `remoteAddress` extern on
`NodeSocket` (~71–90). SSE/POST legs get the same gate or are refused
for authorized services. Size M (S for reject-before-upgrade + echo).
kolt today: token read from localStorage AFTER the socket opens
(client.vl ~38–55), checked per call by SQL; every connection receives
every workspace and task regardless of login. Related: Q4, §4.2,
upgrade mechanics ~466; guide/services.md ~361–378; A38.
