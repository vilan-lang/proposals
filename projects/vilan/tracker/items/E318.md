# E318 — The editor's analysis computes every emitter-only table — the drop plan (`TypeId`s per body), the clone decisions, the resource types — on every keystroke although the language server never emits; the edit-replay differential's JS leg is the only consumer of them on the served path

- status: OPEN — filed 2026-10-13 (incr-52a's find, Order 52)
- kind: design question (editor; S)
- area: LSP & tooling

S7b restores or walks these at item grain where the rows are `Id`s, but the drop plan cannot be recorded (M19 T1c's reason) and is re-planned for every enrolled body on every served keystroke. A `Workspace` flag that lets a seeded analysis skip the emitter-only tail would remove that cost outright — and would blind the differential's JS leg for the served shape, which is why it is a question and not a slice: either the leg keeps a non-skipping mode of its own (the clean-same-shape observation already exists), or the tables stay. Rec: ask; if yes, a small slice after S7b with the differential's JS leg kept on a non-skipping switch.
