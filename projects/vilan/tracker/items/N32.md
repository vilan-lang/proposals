# N32 — the grammar's `extern-args` production omits two forms the parser accepts

- status: OPEN — found by lane smalls while widening the production for `retains` (N29)
- kind: docs
- area: Docs & book
- source: the N29 commit's sweep, 2026-08-29

`spec/grammar.md`'s `extern-args` production was not merely silent about
`retains` (fixed by N29) — it still omits the two `new` forms
(`[extern(new, "Sym")]` and `[extern(new, "module", "Sym")]`, both printed
by `appendix/cli.md`) and the bare `[extern(method)]` with no symbol. All
are accepted by `extern_binding_from_args`
(crates/vilan-core/src/parsing.rs:569). The production should state what
the parser accepts, and whatever gate holds grammar-vs-parser agreement
should learn these rows if one exists (if none exists, that is the wider
finding to record when fixing).
