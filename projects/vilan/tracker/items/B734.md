# B734 — Building a single file with `--backend rust` writes a stray `<file>.css` next to the source

- status: open
- kind: bug (cli)
- area: cli / native backend

A native single-file build leaves `<file>.css` beside the source file. The native backend has no use for the stylesheet output on a server program; it should not be written (or should go to the output directory). Size XS.
