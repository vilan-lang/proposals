# M16 — `scoped_file<T>` emits one identical body per monomorphization

- status: OPEN — audit run 6's F18; recordable, count-based
- kind: perf
- area: Performance & footprint
- source: audit run 6

The five `with_file*` forms share one `scoped_file<T>` whose body is
T-independent, yet each distinct T mints a byte-identical 9-line helper
(file.mjs carries two already). The a33 entry celebrated merging exactly
this class under the monomorphization memo key — the memo key should
consider the EMITTED BODY (or the T-independence) so identical
instantiations merge. Generalizes past fs: any T-independent generic body
pays this.
