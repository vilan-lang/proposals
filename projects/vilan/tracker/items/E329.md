# E329 — A call statement that is exactly 100 columns before its `;` is left on one 101-column line: the Call arm measures `first_line_over_budget` before the `;` is pushed, while a chain statement of the same width splits

- status: OPEN - filed 2026-10-15 (fmt-53's find, Order 53)
- kind: fmt edge
- area: Formatter

`let value = plain_function_call_with_no_chain_at_all(argument_one, argument_two, aaaaaaaaaaaaaa);` inside a function (tab = 4 columns) is 100 columns without the `;`: the statement hook arms the split (the whole statement is 101), but the Call arm's own measure (E314/E321) sees 100 and keeps the arguments inline. The same width as a three-link chain splits at its links. Unchanged since E314 (hole-only); E321 makes it reachable outside markup. Fix: the Call arm counts one column for the statement's terminator when the call is the statement's tail (or carries the armed split's knowledge that the statement overflowed). Sizing XS.
