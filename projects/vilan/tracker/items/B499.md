# B499 — `Source::get(x)` with no annotation does not infer the trait's `T` from the receiver: `Source::get(cell).keys()` → "cannot call method 'keys' on T"

- status: OPEN — filed 2026-10-01 (maps-45's find, Order 45)
- kind: inference (L)
- area: Type system & the type solver

It matters for `MapCell`: the inherent `get(key)` shadows the whole-map read on a concrete receiver, so the whole map is read as an annotated `Source::get(cell)` or `peek`. Rec: infer a qualified trait call's trait arguments from the receiver's impl. Sizing S–M; solver.
