# B160 — `raw(property, v)` and the 1:1 typed method write one slot: the interchangeability contract

- status: OPEN — the owner leaned yes 2026-08-29 and asked for the
  downsides; this item records them, awaiting the ruling
- kind: design
- area: Type system & the type solver
- source: css-s5's refactor finding + the owner's question, 2026-08-29

The motivation: the block↔chain refactor's inverse is partial because
`.padding(space(4))` writes through `with_length`, not the node
`padding: {space(4)};` lowers to — declaring the two interchangeable for
1:1 property methods makes the inverse total there. The downsides,
recorded for the ruling:

1. **Sheet bytes can move for mixed spellings.** A program writing BOTH
   `raw("padding", a)` and `.padding(b)` on one chain today holds two
   slots; unified, last-wins collapses them — emitted CSS changes for
   exactly the programs that mixed. Census first; likely rare; family
   breaking if any exist.
2. **Group methods are excluded by construction.** `padding_x`, `size`,
   `inset` write multiple slots; `raw("size", v)` names no CSS property.
   The contract is per-1:1-method, and the refactor's inverse becomes
   total only over that subset — stated, not discovered.
3. **A standing constraint on std evolution.** Every future 1:1 typed
   method must stay slot-equal to its raw spelling forever; a method that
   later wants normalization (unit clamping, value rewriting) would break
   the contract. Benign today; a fence to write down.
4. **Value rendering already agrees** (raw takes `CssValue` since v0.37 —
   a `Length` emits its `:root` line either way), so the unification is
   the slot key alone; but the refactor converting `raw("padding", "4px")`
   → `.padding(??)` still cannot invent a TYPED value from a string — the
   inverse becomes total at the SLOT level while the conversion still
   emits `raw` for string values. State which totality is claimed.

Recommendation: do it, scoped and fenced as above, with the mixed-spelling
census run first and a golden check that only deliberate programs move.
