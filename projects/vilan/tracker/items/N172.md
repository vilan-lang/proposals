# N172 — `[build] dbg = "keep" | "strip"` (debugging.md Q4, shipped in S1) is missing from the editor schema and the language server's manifest completion — the schema's `[build]` table is `additionalProperties: false`, so VS Code flags a valid `dbg = "strip"` as an unknown key, and completion never offers it

- status: OPEN — filed 2026-10-12 (debug-51's find, Order 51)
- kind: tooling (editor schema + completion; S)
- area: LSP & tooling

`editors/vscode/schemas/vilan-toml.schema.json` lists `[build]`'s keys as debug-names, hook, indent, infer-const, preset, readable-names, run, spaces (and `source-maps` from E257 S5) with `additionalProperties: false`; `crates/vilan-lsp/src/manifest_completion.rs`'s `TABLES` matches it, so `schema_and_listing_agree` passes while both omit the key `Manifest::build_options` reads (`manifest.rs`, `Build::dbg`). Fix: a `dbg` key with the enum `keep`/`strip` in both (the completion's `ValueSet` for an enum string, as `preset` has), and a pin that every `Build` field the deserializer reads is in the listing (the sync test compares the listing to the schema, not either to the struct). Sizing S.
