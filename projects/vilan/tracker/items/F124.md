The design note sweeps/order49/native-49/F99-aliasing-loans.md (native-49, Order 49). `let c: &mut i32 = b;` with `b`, `c` and the owner interleaving is legal vilan (rule 3 aliases, rule 4 forbids only invalidation) and illegal Rust. §2.1: a group whose members' live intervals NEST is a chain of reborrows (`let c = &mut *b;`), free at run time — the common forwarding shape. §2.2: an interleaved group puts its root in the counted cell a captured `mut` binding already uses and makes each view a handle (cell + path, a new `vilan_rt::Place<T>`); every access a momentary borrow; `same(c) /= 10` settles the handle once (native-48's double evaluation); a `borrows` callee gets a per-instance handle signature; a `&mut` callee runs under `with_mut`, refused at compile time when another argument or a closure (F102's reach) touches the group. §2.3 keeps refused: a group over a borrowed parameter root, across an `await`, into an enum payload. Not S: the interval test needs an ordered access list no record holds, and every view read/write path learns the handle.
