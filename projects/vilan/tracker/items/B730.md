# B730 — Native refuses a `map` closure that calls a function returning `any` - unbound generic parameter of `map`

- status: open
- kind: bug (native backend)
- area: native backend

Found by lane db-58. A closure passed to `map` whose body calls a function returning `any` is refused natively as "unbound generic type parameter (parameter 1 of `map`)"; the JS backend builds it. Repro: `scripts/integration/sweeps/order58/repros/repro-map-closure-returning-any.vl`. std::db works around it with a `for`/`push` loop; remove that when this is fixed. Size S-M.
