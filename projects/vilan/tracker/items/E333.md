# E333 — a generic enum's variant as a LIST or TUPLE element or as a method receiver hovers bare - `Some` in `[Some(1), None]`, `(Some("a"), 2)` and `Some(4).map(..)` read `Option::Some`, with no instantiation and no payload

- status: OPEN — filed 2026-10-16 (editor-54's find, Order 54)
- kind: editor (hover; XS)
- area: Editor

`variant_use_labels` (hover_labels.rs) settles a variant's instantiation from the return slot, an annotation, the initialized binding's type and a plain call's declared parameter (E317, E328); a container element and a receiver have none of those facts. Read the element type from the container's recorded type (the list's or tuple's `expr_types` row) and the receiver's from the member call's subject type. Pin: the three shapes with `Some`, `None`, `Ok`, `Err`.
