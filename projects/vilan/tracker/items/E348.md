# E348 — A call under an index (`f(..)[0];`), an ascription (`f(..) as i32;`) or a lift continuation (`f(..)?.x;`) never breaks its arguments, at any width

- status: OPEN - filed 2026-10-26 (fmt-55's find, Order 55)
- kind: fmt edge
- area: Formatter

E337 gave the statement's permission to a call under `!`, `?` and `.field`; the same statement-ending postfixes `[index]`, ` as T` and `?.continuation` still print their subject without it, so a 110-column `let a = f(argument_one, argument_two, <..>)[0];` stays one line. The mechanism is E337's `enter_postfix_subject` (the suffix width of an index is the index's printed width, of an ascription ` as ` plus the type, of a lift continuation the continuation's - the three need their printed width up front, which the field's name did not). Sizing S. Rec: only if a real line shows up; the estate has none.
