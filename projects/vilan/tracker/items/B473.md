# B473 — through a SUBTRAIT bound, a supertrait method with a DEFAULT runs the default even when the type OVERRIDES it — 0.41.1 prints 'the override' then 'the default'; A142 exposed it (`map_each` took `ListCell`'s lazy default instead of its observer, keeping 92 cells live natively) and `RemoteSource`/`KeyedSource` are exposed the same way (through a subtrait bound they would take the lazy default, not the lease path)

- status: OPEN — filed 2026-09-29 (Order 44, reactive-44's find 1); HIGH
- kind: bug (MISCOMPILE — both backends; predates A142)
- area: Type system & the type solver

Dispatch through a subtrait bound must resolve the supertrait member against the receiver's IMPL (override first, default second), as a direct supertrait bound does. Pin both backends; un-ignore the pin; remove `map_each`'s workaround. Sizing S–M; solver, Order 45 FIRST (miscompile).
