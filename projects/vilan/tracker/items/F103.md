# F103 — native: F49's sibling — a FIELD read on a BOXED binding copies the WHOLE value first: `log.lines.len()` emits `log.get().lines.len()`, cloning every list in `log`; in std it is `write_at`'s `woken.get().feeds` / `.slots`, six whole-`StoreWoken` copies per `Store` write

- status: OPEN — filed 2026-10-05 (papers-47's find, Order 47)
- kind: perf (native) (S)
- area: Native targets & rendering

`Captured::get` (= `Shared::get`) returns a clone of T; a field read through a boxed binding takes it and reads one field. Probe s1 (20,000 store writes: ~4,150 Ir and 15 allocations per write) carries `(woken.get().feeds).clone()` twice and `woken.get().slots` once per write in `write_at` (store_core.vl:552-575). Fix with F49: read a field through `x.borrow().field` (and `&*x.borrow()` for `&self`), so the copy is of the field the read owes, not of the whole value. Pin: the store probe's copy count; ride it with F49 before A153's server half runs natively. Sizing S.
