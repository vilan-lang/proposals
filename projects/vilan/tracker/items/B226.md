# B226 — a self-import (or a cycle back) into the ENTRY module makes it load as a module and skips its walk and derive expansion: `main` and every `[derive]` vanish

- status: OPEN — the owner's find while migrating kolt (2026-09-04); reproduced at 289e2a2b by the triage lane with the exact message
- kind: bug
- area: Type system & the type solver

`import pkg::client::SidebarTab;` at the top of the ENTRY client.vl beside
`[derive(PartialEq)] enum SidebarTab { Messages }` → "type 'SidebarTab'
does not implement the `PartialEq` operator; add `impl SidebarTab with
PartialEq`". Discriminators: delete the import → clean ("a new file
works"); the same self-import in a NON-entry module → clean; self-import
a function instead → "Cannot execute program without a main function"
(the entry's whole item table is lost); a cycle back through the entry
(client → views → client) → the same. Ruled out: declaration order, a
`mod` wrapper, a name collision (that gives a correct duplicate-impl
error), browser/node platform sharing. kolt carries the latent form at
sidebar.vl ~7 (`import pkg::sidebar::SidebarTab;` beside its own
declaration) — harmless only because sidebar.vl is not an entry.

Cause: `is_entry_module` (analyzer.rs ~43853) is origin-blind —
`canonical_path(&module_path) == canonical_path(entry_path)` — meant
for "a std file opened directly in an editor" (~43714), but a
`pkg::<entry>` import resolves back to `entry_path` and flips it;
`entry_is_module` then skips the entry-as-program walk (~44771) and
the entry's macro/derive expansion (~44193, ~44708), so the derive is
expanded nowhere. Nothing in vilan-core detects a self-import or an
import cycle.

Fix (S–M, low risk): gate the flag on `Origin::Std | Origin::Dep(_)`;
for an `Origin::Pkg` self/cycle re-entry alias the module name to the
already-seeded entry scope (~43959) instead of building a second
module; warn on a direct self-import. Pins: the lane's `proj/` (entry
with a self-import: the derive holds, `main` holds; the cycle form;
the non-entry control). Related: B201 (derive inside a mod).
