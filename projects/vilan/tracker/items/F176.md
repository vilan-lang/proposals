# F176 — `kit::text_input`: a blinking caret, and a drag held still past the field's edge that keeps scrolling (both need a host timer)

- status: open
- kind: feature gap (native UI; host timer)
- area: crates/vilan-rt-gfx/src/host/shell.rs (`wait_for`), crates/vilan-rt-gfx/src/ui, vilan/std/src/ui/kit/inputs.vl

The blink needs: window focus tracked in the host (winit's `Focused` is ignored now); a host-owned blink deadline merged into `shell.rs`'s `wait_for` beside the program's deadline and F169's drain wake; a caret-visible flag that repaints only the edited text (touches F170's scene caching); the blink phase reset on every edit; a shell with an injectable clock so the pin has no timing in it. Budget: an idle unfocused window draws nothing, a focused input at most two frames a second. The same timer serves auto-scroll while a drag is held still past the edge.
