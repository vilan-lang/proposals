# B256 — `Shared::read()` hands out the cell's STORAGE: `SharedValue` lowers to the bare slot `self.v` though the intrinsic table says "a copy of the cell's value" and spec §6.1 says a value-returning signature copies; the clone pass exempts every call ("calls own their result"), so `let b = h.read()`, `mut c = h.read(); c.push(x)` and `SignalCell::get()` all alias the cell (`c.push` grows the cell)

- status: OPEN — found under B255 (2026-09-06); a ruling wanted
- status update 2026-09-07 (Order 29, lane rule1-29 @47d7a599): the default ruling IMPLEMENTED and MEASURED, then HELD — std copies deep aggregates per notify (`bind_each`'s `row_views`/`row_owners` reads, `drain`'s wave list): +20% CPU on `bind_each` at 500 rows, +12% on A44's selector, +25% on a batch drain, +344% on a raw `get()` (node, loadavg 101–104, medians of nine); three ignored pins carry the numbers. Three options: land at these numbers; clone at every read (worse); or B267 first — a cell-aware last-use elision, since both hot std reads have a dead or walked source — then re-measure and land. Recommended: B267 first.
- kind: bug
- area: Memory model (rule 1 / rule 2)

Probe on 757d3f4b (`assign.vl`): `let b = h.read(); h.write().push(9)` — `b` reads 5; `mut c = h.read(); c.push(10)` — the CELL reads 6. Emitted: `const b = h.v; let c = h.v;` — no `__clone`. `compute_clone_sites` copies only PLACES (`is_place_expr`: a local or a field) and leaves calls alone on the premise the spec states in §6.1 ("a call owns its result"); `SharedValue` is a call that returns storage, so the premise is false at exactly this intrinsic, and `SignalCell::get()` (`self.value.read()`) inherits it. `Shared`'s header comment says binding shares the CELL — that is the handle; the VALUE read out is declared `read(self): T`, a value return, which §6.1 says copies ("a signature that hands back a value hands back a value"; only a `borrows` projection names storage).

Two fixes, and which one is the owner's ruling: (a) `SharedValue` emits `__clone(self.v)` — every read of a list/map/struct deep-copies, including `bind_each`'s three `read()`s per effect and every `for x in cell.read()`; simple, and the cost wants measuring on kolt's client leg before it lands; (b) the clone pass treats a `SharedValue` result (and `get()`, a call returning one) as a PLACE: a binding, assignment, construction slot or `own` argument fed by it copies, a temporary (`for item in cell.read()`, `cell.read().len()`) stays free, and rule 2's liveness elision cannot fire because the source is not a local — rule 1's cost only where two owners come to exist. My recommendation is (b). Either way the intrinsic-table comment and `shared.vl`'s doc ("project the cell's value") should say the same thing the emission does.
