# B769 — Native: a closure that writes through a captured scalar `&mut` view does not build (rustc E0070); JS is correct

- status: open - filed 2026-11-27 (lane `keys-s3a`'s find; pre-existing on `next` @6744ee9d, no key involved)
- kind: backend defect (native: a checked program does not build)
- area: crates/vilan-rust/src/lib.rs (a captured scalar view on the left of an assignment)

Repro:

```
fun call(f: || void) {
	f();
}
fun bump(acc: &mut i32) {
	call(|| {
		acc = *acc + 1;
	});
}
fun main() {
	mut sum = 1;
	bump(&mut sum);
	print(sum);
}
```

JS prints `2`. `vilan run --backend rust` stops at rustc, "invalid left-hand side of assignment": the capture is emitted as a read (`acc.get()`) and then assigned to. Any callee that takes the closure hits it.

Why it matters now: it keeps `k.view(&s, |x| { acc = *acc + *x; })` pinned on JS only (inference pin `maybe_keys_a_continuation_takes_a_closure_capturing_a_view`).
