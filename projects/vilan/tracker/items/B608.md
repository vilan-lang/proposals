# B608 — B598's static twin: `List::describe([1, 2])` in a file importing only `pkg::describe::Describe` is refused "'describe' is not an inherent member of 'List': 'Wire' and 'Describe' provide it; call 'Wire::describe(..)' or 'Describe::describe(..)'" — the steer names std's `Wire`, which the file does not reach

- status: OPEN — filed 2026-10-10 (solver-50's find, Order 50)
- kind: semantics (S)
- area: Language & type system

B598 narrows a METHOD call's trait candidates to the traits the calling file reaches (B515's rule); the static path (`Type::member`, the static-accessor arm of resolve_world that ranks `method_member_candidates`) does not, so its refusal names an unreachable trait. Apply `candidates_reached_at` there too (it is a refusal either way — a trait method is not an inherent static — but the steer should name only `Describe::describe(..)`). Sizing S; solver.
