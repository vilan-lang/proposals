# B470 — a resource can never become `dyn` ("a trait object's teardown would have to be dispatched through its table") — A142's selectors with arms of different types and `TransientSource::latest()`/`is_pending()` return `dyn Flow`/`dyn Pipe`; RULED: a resource with NO `Drop` anywhere inside it may become a trait object (there is no teardown to dispatch); a resource with `Drop` stays refused

- status: OPEN — filed 2026-09-29 (Order 44, native-44's find 1); RULED by the owner the same day: allow; solver-44 builds it after B469
- kind: language rule (RULED 2026-09-29) — trait objects of resources
- area: Type system & the type solver

The trait object of a Drop-less resource is itself a resource (move-only) — coercing into `dyn` moves the value, and the `dyn` value obeys the affine rules (no copy, a use after move refused). Both backends: JS carries the pair as today; native (F56's emission) must build the erased pair for a resource without cloning (native-44 pins it after the analyzer change). Pins: a Drop-less resource into `dyn Trait` accepted and moved; a second use refused; a `Drop` resource into `dyn` still refused with today's message; A142's mixed-arm selector shape. Sizing S–M; solver-44 after B469, native parity in native-44.

- 2026-09-29 (the owner, mid-Order 44, on solver-44's design question): HOW it decides RULED — DECLARED, not inferred: `[resource]` extends to TRAIT declarations; `dyn T` is a resource (move-only) exactly when `T` is declared `[resource]`; a Drop-less resource may be erased only into such a trait's `dyn` (else refused with the steer 'mark the trait `[resource]`'); a data type erased into it is move-only as that `dyn` value; an undeclared trait's `dyn` stays data (every existing `dyn Source<T>` copy untouched); a resource with a `Drop` inside stays refused. std marks `Flow` and `Pipe` (reactive-44). Rejected: solver-44's per-trait INFERENCE from erasures anywhere in the program (non-local — an erasure in one module or a library turns a copy elsewhere into an error). Supertrait inheritance: solver-44's choice, reported (rec: inherited).
