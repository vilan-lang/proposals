# B743 — Native backend: a local closure that awaits is emitted as a spawned task while its call sites still await it, so cargo refuses the build

- status: open
- kind: bug (native backend; async closures)
- area: crates/vilan-rust/src/lib.rs (closure emission, async inference at call sites)

`let board = |what: str| { let held = clipboard_text(); print(..); }; board("first");` in `fun main()`: the closure's body awaits, the emitter makes it a spawned task, and the call site awaits the call as if it answered a future. Decide which side is right (a closure that awaits is an async closure whose call awaits, as a function's is) and pin on both backends in `native_differential`. RELATED, not reproduced in isolation: `.width(..).padding(..)` on a `TextInput` built inside a `when` closure in the todo example's `check` came out `async` and was refused; look for it while fixing this one, in `vilan/examples/ui-todo/main.vl`'s `spare_screen` helper, which exists only as the workaround.
