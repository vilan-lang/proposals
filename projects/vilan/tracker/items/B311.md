# B311 — MISCOMPILE: `Style::pseudo` accepts a name containing `:` (the slot key's own delimiter — `rule` builds `media:condition:property` and every consumer `split(":")`s it), so an ENCLOSING combinator emits a WEAKER selector: `attribute("data-open", Some("true"), pseudo("hover:not(:active)", S))` → `.sX[data-open="true"]:hover` with the `:not(:active)` GONE (and the property field reads `not(`, so `without_covered`'s family resolution is computed against garbage); pre-existing, and LIVE IN KOLT: `styles.vl:48–49` write `pseudo("hover:not(:active)", ..)` and `pseudo("focus-visible:not(:active)", ..)` — not biting only because nothing wraps them. The fence (`:` refused in `pseudo`'s name, as `check_attribute_name` refuses it) is BREAKING for kolt and needs the spelling that replaces it: A89's `not` negates the ENCLOSING condition, so "hovered AND not active" (two pseudo-classes in one slot) is unspellable today — `hover(not(active(S)))` means `:not(:hover):active`
