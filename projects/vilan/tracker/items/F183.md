# F183 — Path masks: edge pixels come out darker where a stroke's outlines overlap (zeno adds coverage there): up to 0.7 of a pixel's coverage, visible as slightly heavy inner edges at 48 dp

- status: open
- kind: quality (native graphics; path rasterisation) — owner's eye
- area: crates/vilan-rt-gfx/src/path/{mod,masks}.rs (`stroke_outline`, the mask fill), zeno 0.3.3

Sweep of all 1,999 Lucide icons against tiny-skia (mean absolute coverage difference over inked pixels): 16 dp average 0.051 / worst pixel 0.62; 24 dp 0.027 / 0.53; 48 dp 0.014 / 0.69. What is left after the two stroker fixes is this: zeno's stroker emits an outline whose pieces overlap (the two sides of a closed contour, joins, contours lying on each other in the icon), and the accumulation rasteriser ADDS partial coverages at an edge where they overlap, so such an edge pixel is darker than the union's true coverage. Seen as a slightly heavier inner edge on small closed shapes (`grape`, `shrink`, `server-off`, `columns-4`). It is a property of the rasteriser, not the stroker: tiny-skia's stroker would not change it. Against tiny-skia at 16x averaged down (the nearest thing to true coverage), ours is the CLOSER of the two on straight edges at 16 dp (`columns-4`: ours 0.040, tiny-skia 0.073), so this is not one-sided. OPTIONS, none tried: (a) accept (the integrator's recommendation for icon sizes; the eye does not find it at 16 to 24 dp); (b) rasterise a stroke's outline through a union first (a boolean pass, or a scanline rasteriser with a non-additive winding rule: tiny-skia as a real dependency for strokes, R2's named fallback; it adds no package on Linux but is newly compiled on Windows and macOS); (c) supersample stroke masks 2x vertically and average (masks are cached, so the cost is at first use). Related, R5's known gap stays: zeno bevels MITER joins sharper than 90 degrees; drawing the whole Lucide set with miter joins put 56 icons up to a whole pixel off, so a set that uses miter joins needs (b) or a miter fix of our own in `stroke_outline`. Lucide itself uses round joins and caps throughout and is not touched by it.
