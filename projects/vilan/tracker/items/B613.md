# B613 — `[derive(Storable)]` in a program that never imports `std::reactive::store` read "expanded before std's `reactive/store.vl` declared its `Storable` macro: a compiler load-ordering bug (B21's class); please report how this module is reached" — a missing import blamed on the compiler

The B21 sentence assumes every std derive's module loads with every program; that holds for compare/default/debug/json/hash (the analyzer's always-loaded set) and not for `reactive/store.vl` (A142 S7's Storable), which loads only by an import. Fixed in fix-51: `IMPORTED_STD_DERIVES` names the derives whose module an import loads, and the refusal writes the import line (`import std::reactive::store::Storable;`).
