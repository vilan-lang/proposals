# B593 — A list of function ITEMS types as `List<fn double(i32): i32>` and calling an element is refused on both backends — "cannot call this as a function: it is fn double(i32): i32" — where a bound item (`let g = double; g(4)`) and a closure-typed list both call

- status: OPEN — filed 2026-10-09 (native-49's find, Order 49)
- kind: bug (analyzer; S)
- area: Type inference

`let fs = [double, double]; print(fs[1](3));` is refused. The element type is the item's own `Type::Function`, and the value-call check admits a closure type and a binding of an item but not an item-typed EXPRESSION. Either the list literal coerces its items to the closure type (`function_closure_type`, the coercion F119 discussed) or the call admits `Type::Function` at any callee. Expected: 6.
