# B750 — Native: three scalar-view reads are rustc E0308 - `if x` over `x: &bool`, `x is Named::B` over a str-backed enum's view, and an inline `match &holder.kind { .. }` over a str-backed enum

- status: open
- kind: native backend defect (cargo refuses; scalar views)
- area: crates/vilan-rust (the emitter's view reads and string-backed enum patterns)

Each fails loudly at rustc, so nothing wrong runs. (1) `if x` with `x: &bool`: the condition is the reference. (2) `x is Named::B` with `x: &Named`, `Named` str-backed. (3) `match &h.kind { Named::A => .. }` inline over a str-backed enum matches `&Rc<str>` against `&str`. Fix together with B749's rule so both backends read a scalar view the same way at a test position; pin each through the native differential.
