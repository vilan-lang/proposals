# E363 — `vilan fmt` prints an empty import set with two spaces (`{  }`), and nothing says the statement imports nothing

- status: open
- kind: polish (formatter; a missing lint)
- area: crates/vilan-core/src/formatter.rs (the set printer), the unused-import warning

Two small things. (1) The set printer writes `{ ` + members + ` }`, so no members prints `{  }`; an empty block prints `{}` (`an_empty_block_prints_as_a_pair_of_braces`), and an empty set should agree. `format("import std::json::{  };")` is the one-line repro. (2) An import whose set is empty binds nothing, and neither the unused-import warning nor Organize Imports notices it: Organize prunes a set whose members are all unused, but a set written empty has no member to call unused. Proposed: the unused-import warning names it ("this import brings nothing in"), and Organize Imports drops the statement. A side note for whoever takes it: an empty set does not load its module (a file whose only reach to `m` is `import m::{};` gets no auto-import candidates from `m`), which is consistent with importing nothing and probably right; say so in the pin.
