# A102 — `lazy let` bindings and HMR: excluded from transfer in v1 (`TransferForm::Excluded` — a swap carries a VALUE and a lazy binding may not have one; adopting the cell would hand the new bundle the old bundle's thunk), so a lazy binding holding state that should survive a hot swap has no answer today

- status: OPEN — filed 2026-09-15
- kind: design
- area: Reactive core & UI

Decide: transfer the cell only when `state == done` (the value survives, the thunk is dropped) — the honest middle; pin under the HMR round harness.
