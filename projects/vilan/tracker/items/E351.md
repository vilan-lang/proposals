# E351 — A decline's line inside ONE large item can still fall back to the first token the canonicalization moved when the item has canonicalizations on both sides of the divergence

- status: OPEN - filed 2026-10-26 (fmt-55's find, Order 55)
- kind: fmt edge
- area: Formatter

B671 localizes the net's answer to the top-level item the divergence falls in (an import run is one item) and asks the prefix, suffix and deletion alignments of that item alone. Inside one big function with a deletion (a trailing comma) before the divergence and a permuted run (a style chain, an element head, a css block) after it, all three still fail and the answer is the item's first moved token. Not observed on a real printer bug (none is open); needs a planted print to see. Rec: if one is ever met, recurse the same cut over the item's top-level statements. Sizing S.
