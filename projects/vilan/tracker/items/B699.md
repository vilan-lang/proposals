# B699 — NATIVE: a field read of an operator's result (`(a + b).value`) is refused with "field read of an unresolved subject" - the emitter has no place for the operator call's value

- status: OPEN - filed 2026-11-03 (lane solver-56's find)
- kind: native backend defect (cargo refuses)
- area: Native

The native emitter resolves a field read's subject to a place or a binding; an overloaded-operator call is neither, so the read fails where a method call's result (`a.add(b).value`) would be a temporary. Rec: treat an operator call as a call expression in `consumed_value_of` (a temporary, like any call) - the same path F153's lane walks. Pin in the native differential. Sizing S.
