# B582 — an impl head over a fixed array cannot bind its element: `impl [type T; 3] with Count { .. }` is refused "cannot find type 'T'" at both `T`s, while `impl [i32; 3] with Count` compiles (B177) and impl selection already binds through an array's element (`bind_subject`'s and `collect_subject_binders`' `Type::Array` arms)

- status: OPEN — filed 2026-10-08 (std-48's find, Order 48)
- kind: solver: impl head (S)
- area: Type system & the type solver

The subject-binder registration walk that admits `type T` in an impl head (struct arguments, tuples) does not descend into `Node::ArrayType`, so the binder is never declared and every mention of it is unresolved. Selection is ready for it: `impl_select::bind_subject` binds `T = i32` from `[T; n]` against `[i32; n]`. Fix: the registration walk's array arm.
