# B178 — `fun main(p: bool)` compiles and emits broken JS

- status: OPEN — traits-core lane's find (Order 23)
- kind: bug
- area: Type system & the type solver
- source: lane traits-core, 2026-08-31

A parameterized `main` is accepted and the emitted program hoists the
body so the parameter is undefined at runtime (`ReferenceError:
condition is not defined` calling `main(true)`). Nothing in the test
estate uses the shape. Either refuse parameters on `main` with a
message (probably right — nothing can call the entry with arguments),
or emit correctly; ruling decides which. Found while shaping a
fixture; worked around by moving the parameter to a helper.
