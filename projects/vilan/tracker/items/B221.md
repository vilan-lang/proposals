# B221 — a diverging statement that is not the LAST statement does not exempt the tail: `fun g(): i32 { for { … } print("dead"); }` is refused

- status: OPEN — lane b204's find (2026-09-03); pre-existing, B124's exemption list
- kind: bug
- area: Type system & the type solver

`check_return_position` looks only at the body's tail and the LAST
statement, so a body that diverges earlier (an endless loop, a
`panic`, a `ret` — `fun g(): i32 { ret 1; print("dead"); }` fails
identically on next) still owes a tail value. It is the one shape
where paint (which grays `print("dead")`) and the checker describe
the same block differently. Fix: `check_return_position` asks
`Divergence` about ANY statement of the body (the first diverging
statement makes everything after it unreachable and the tail exempt),
which is B124's exemption list widened once; pin `ret`, `panic`, the
endless loop, and a control where the diverging statement is inside
a non-taken branch.
