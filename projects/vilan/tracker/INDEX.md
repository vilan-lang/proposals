| [C14](items/C14.md) | NEW — `SignalCell` (and `Owner`) off `Shared` boxes and onto `Rc` or OWNER-ATTACHED arena `Handle`s — the necessary step for native apps with native code and NO garbage collector (F1). Today `SignalCell<T> { value: Shared<T>, subscribers: Shared<List<Subscriber>>, identity }` and `Owner { cleanups: Shared<..>, disposed: Shared<bool> }`; `Shared` is a compiler primitive (`external struct`, `primitive_struct_ids` 'Shared', 8 analyzer sites) whose doc says 'reference-counted' but whose JS backing is a plain object box the HOST GC reclaims — nothing counts, cycles (cell ↔ subscriber closures capturing cells) are the GC's problem, and a disposed owner's cells stay readable forever.
