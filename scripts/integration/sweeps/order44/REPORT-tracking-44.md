What landed: `track()` a blanket on every `Source` (so `dyn Source` too), reading `tracking` through the strict `get` (a `track()` outside every body is the coverage error; no run-time lookup; `get()` never tracks). Every body injected with `context (owner_scope, tracking, ambient_nursery)` and run through `run_tracked` beside S2's `run_body`: a `Derive` follows what it tracks; a `Switch`/`SwitchSome`/`AndThen` selector re-selects when a tracked source changes (same record as the outer — one re-select per turn; a `switch_some` going `None` drops its last selection's tracked edges); an `effect` re-runs with the latest input. Free `derive(|| body)` returns `TrackedDerive<T>`, a `[resource]` node with `Flow` + `Pipe` (sealable once, no `get`). Dependencies are the last run's reads: an edge to a source read again is kept, new ones attached, dropped ones detached after the new ones are up; recognising a source needs the new trait member `Source::identity(): Option<i32>` (default `None`; `SignalCell` and `MemoCell` return their cell's identity; a `None` source gets a fresh edge each run). Edges wake as derivations (dedup with the consumer's wake in a turn). `effect` ordering: the re-run record is minted after the input's record and before the first run (one run per turn when input + a tracked source change together; parents before children). A scope lasts one run (an epoch): a closure created in a run and called later registers nothing. A source that notifies WHILE an edge is being attached (a mirror's in-process seed) makes the stage run again and return the fresh value (found and pinned). `on_change` over a pipe now runs the pipe's bodies once at subscription (value discarded, observer not called) — without it `derive(|| x.track()).on_change(..)` never fires. BREAKING: body clauses have three contexts (a closure VALUE typed with the old two-context clause no longer forwards; literals unaffected); pipe bodies run once more at subscription under `on_change`.
