## Breaking changes (release notes)
S1: `Source.map` → `derive`. A derivation is a move-only pipe: no `get()`, consumed once — one consumer, or a seal (`.memo()` → read-only `MemoCell<T>`; `.cell()` → writable `SignalCell`; `.memo_global()`/`.cell_global()`; `.sample()` reads once, subscribes to nothing). A second consumer is refused ("use of 'p' after it was moved": sealing twice, branching, two `sub`s). `.cell()` exists only on pipes (`root.cell()` gone; `cell.memo()` does not exist). A custom `Source` implements `get` + `on_settle(self, subscriber): Subscription` (not `on_change`); `attach_observer` optional. `flatten` is the Option join only; the total join is `switch(|inner| inner)`. A derived `combine` input or a `dyn Source<T>` value is sealed with `.memo()`; `divorce` takes a `Source`. `std::ui` bindings take `own S: Flow<T>` (`bind_text`, `bind_class`, `bind_styled`, `toggle_attr`, `show`, `style_var`, `attr`, `bind_attr`, `child`, `when`, `when_some`, `swap`); `each`/`each_values`/`each_by` keep `Source<List<T>>` (a derived list is sealed); `swap_split` takes a `Source`. `own self` receivers: `Slot::place`, `AttrValue::apply`, `AttrBinding::bind_attribute`, `MaybeSignal::bind`. New names: `Flow<T>`, `Pipe<T>`, `Instance<T>`, `MemoCell<T>`; `Source::constant(v)`, `.sample()`; stages `Derive`, `Switch`, `SwitchSome`, `AndThen`, `ThenSome`, `Combine`, `Distinct`, `DistinctBy`.
S2: an owner per run on every body (`effect`, `derive`, `switch`/`switch_some`/`and_then` selectors); registrations released before the next run and with the consumer; a task the run starts is cancelled with the run. `effect`/`scoped_effect` are one operation (`scoped_effect`, `scoped_effect_on_change` deprecated aliases that warn). Bodies are `context (owner_scope, ambient_nursery)` closures (a named function must be wrapped — B478). `Owner` is one epoch of a single cell; `OwnerCell` exported; `Owner::renew`/`Owner::nursery` `[internal]`.
